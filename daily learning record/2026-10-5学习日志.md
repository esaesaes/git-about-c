- 学校网站的格式要求很离谱：
```.c
#include <stdio.h>

int main(void)
{
	int arr[11];
	int i = 0;

	printf("\n请输入11个数字：");
	for (i = 0; i < 11; i++)
	{
		scanf("%d", &arr[i]);
	}

	printf("\n解密结果为：");

	for (i = 0; i < 11; i++)
	{
		printf("%c", arr[i]);
	}

	return 0;
}
```

比如int i = 0;相当于int i空=空0；

- `=` 前后加空格：`i=0` → `i = 0`
- `<` 前后加空格：`i<11` → `i < 11`
- `for` 后加空格：`for(` → `for (`
- for 里面的分号后加空格：`for(i;i<11;i++)` → `for (i = 0; i < 11; i++)`

## 总结：我需要改的习惯

1. `main` 空参数写成 `int main(void)`。
2. 缩进统一用 Tab，配置编辑器。
3. 运算符 `= < > + -` 等两侧加空格。
4. 逗号后加空格。
5. `for`、`if`、`while` 后加空格。
6. for 循环变量要在 for 里初始化，不要省略。
7. 注意循环结束后变量的值，避免下一次循环不执行。
8. 大括号、return、语句块都要统一缩进。

- 转义符\

- 运算的优先 eg:a=b>3?:2;4

  - 先b>3;b=5,条件为真；
  - 选择：后面的第一个值，2；
  - 将2赋值给a
  - a=2

- \- 算术运算符**：如 `*`、`/`、`%`（取模） —— 优先级最高

    关系运算符**：如 `<`、`<=`、`>`、`>=` —— 次之

    逻辑运算符**：如 `&&`、`||` —— 再次之

    赋值运算符**：如 `=`、`+=`、`-=` 等 —— 优先级最低
