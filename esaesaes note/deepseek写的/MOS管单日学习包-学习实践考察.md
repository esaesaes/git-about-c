# 第 1 部分 知识

## 1. 结构与端子

### 1.1 物理结构 ★必学

MOSFET = **M**etal-**O**xide-**S**emiconductor **F**ield-**E**ffect **T**ransistor，金属-氧化物-半导体场效应晶体管。

以最常用的 **N 沟道增强型**为例，剖面是这样的：

```
              G (栅极，多晶硅/金属)
              │
        ┌─────┴─────┐
        │   SiO₂    │  ← 绝缘层！厚度只有几十纳米
   ┌────┴───────────┴────┐
   │  N+      P 衬底   N+ │
   │ 源区     (Body)  漏区│
   └──┬────────────────┬─┘
      │                │
      S              D
      └────────┬───────┘
               │
          (与衬底短接)
```

**三个关键点：**

1. **栅极和沟道之间是绝缘的（SiO₂）** → 这就是"场效应"：用**电场**控制，不靠电流
   → **输入阻抗极高（$10^9\ \Omega$ 以上）**，稳态下栅极几乎不吃电流
2. **栅氧层极薄（几十 nm）** → 耐压有限，**通常 $V_{GS}$ 上限只有 ±20 V**，静电就能击穿
3. **衬底（Body）与源极短接** → 后面讲的"体二极管"就是这么来的

### 1.2 端子与符号 ★必学

| 端子 | 英文 | 作用 |
|---|---|---|
| **G** | Gate 栅极 | 控制端，加电压控制沟道 |
| **D** | Drain 漏极 | 电流流入/流出端 |
| **S** | Source 源极 | 电流流出/流入端（**N 沟道低边时接 GND**） |
| **B** | Body 衬底 | 通常与 S 内部短接，不单独引出 |

**N 沟道增强型符号（重点看箭头和体二极管方向）：**

```
        D                        D
        │                        │
        │                   ┌────┴────┐
   G ───┤             G ────┤  │   ┌──┴──┐
        │  ┌──|<|──┐         │  │   │ ▲ │ 体二极管
        │  │       │         │  │   │ │ │
        │  └───────┘         │  │   └──┬──┘
        │                        │      │
        S                        S
    （简化符号）              （含体二极管）
```

**记忆要点：**

- **箭头**：N 沟道箭头**指向沟道（向内）**；P 沟道箭头**背离沟道（向外）**
- **体二极管**：N 沟道 **S → D**（阳极在 S）；P 沟道 **D → S**
- 三条"沟道线"是**实线** = 增强型（默认关断）；**虚线/连续线** = 耗尽型

> ▲ **最容易记反的地方**：体二极管方向。**用一句话锁死：N 沟道体二极管从 S 指向 D，所以低边开关接感性负载时，它天然就是续流二极管。**

### 1.3 四种类型 ★必学

| 类型 | 导通条件 | 常见度 | 用途 |
|---|---|---|---|
| **N 沟道增强型** | $V_{GS}>V_{GS(th)}$（正电压） | **最常用** | 低边开关、功率变换 |
| **P 沟道增强型** | $V_{GS}<V_{GS(th)}$（负电压） | 常用 | 高边开关、防反接 |
| N 沟道耗尽型 | $V_{GS}=0$ 就导通，负压关断 | 少见 | 恒流源、射频 |
| P 沟道耗尽型 | $V_{GS}=0$ 就导通 | 很少见 | — |

> **"增强型"和"耗尽型"的区别**：增强型是"**需要加电压才有沟道**"（默认关断，适合做开关）；耗尽型是"**本来就有沟道，需要加电压才能关掉**"。

## 2. 体二极管 ★必学

### 2.1 它从哪来

衬底（P 型）与漏区（N+）之间天然形成一个 PN 结 —— 这就是**寄生体二极管（Body Diode / 续流二极管）**。

**方向**：N 沟道 **阳极在 S，阴极在 D**（因为衬底 P 接 S，漏区 N+ 是 D）。

### 2.2 它的作用（既有用又危险）

**有用的地方：**

| 场景 | 体二极管的作用 |
|---|---|
| 低边开关驱动感性负载（电机/继电器） | **天然续流路径**，线圈关断时电流通过体二极管回流 |
| H 桥 / 半桥 | 桥臂换流时的续流通道 |
| 同步整流 BUCK | 死区期间由体二极管导通 |
| 防反接（PMOS 高边） | 上电瞬间提供通路 |

**危险的地方：**

| 问题 | 说明 |
|---|---|
| **反向恢复慢** | 体二极管是 PN 结（不是肖特基），反向恢复时间 $t_{rr}$ 长 → 半桥换流时产生大尖峰和损耗 |
| **压降大** | 体二极管 $V_F$ 约 0.7~1.5 V（随电流），比 MOS 导通压降大得多 → **发热** |
| **不能长期当整流管用** | 很多设计里要并联外部肖特基来分担 |

> ▲ **所以"MOS 管天然带续流二极管"只对了一半**：低频小电流场合够用；**高频 PWM（如 20 kHz 以上）场合，体二极管的反向恢复会成为主要损耗和尖峰来源，必须评估甚至外并肖特基。**

## 3. 三个工作区 ★必学（今天的重点之一）

### 3.1 三个区的定义

以 N 沟道增强型为例，设过驱动电压 $V_{ov}=V_{GS}-V_{GS(th)}$：

| 工作区 | 条件 | 沟道状态 | 特性 | 用途 |
|---|---|---|---|---|
| **截止区** | $V_{GS}<V_{GS(th)}$ | 无沟道 | $I_D\approx0$（只有漏电） | 开关"断" |
| **可变电阻区**<br>（线性区 / 欧姆区） | $V_{GS}>V_{GS(th)}$ 且 $V_{DS}<V_{ov}$ | 完整沟道 | 像一个**受 $V_{GS}$ 控制的电阻** | **开关"通"！** |
| **恒流区**<br>（饱和区 / 放大区） | $V_{GS}>V_{GS(th)}$ 且 $V_{DS}>V_{ov}$ | 沟道在漏端**夹断** | $I_D$ 主要由 $V_{GS}$ 决定，几乎不随 $V_{DS}$ 变 | 放大、恒流源 |

**输出特性曲线：**

```
   Id
    │         ↑ 饱和区（恒流区）
    │         │  曲线几乎水平
    │  ┌──────┼──────────── Vgs 大
    │  │      ├──────────── Vgs 中
    │  │      ├──────────── Vgs 小
    │  │      ├──────────── Vgs = Vth (临界)
  ──┼──┴──────┴──────────── Vds
    0   可变电阻区
        (Vds < Vgs-Vth)
```

### 3.2 ★★★ 术语陷阱：MOS 的"饱和"和 BJT 的"饱和"是反的！

**这是跨模电数电最容易混淆的一点，务必记牢：**

| 术语 | BJT（三极管）里指 | MOSFET 里指 |
|---|---|---|
| "饱和" | $V_{CE}$ 很小，**像闭合开关**（导通最好） | $V_{DS}$ 很大，**像恒流源**（导通很差！） |
| 做开关要用 | **饱和区** | **可变电阻区（线性区）** |

> ▲ **如果你跟别人说"让 MOS 工作在饱和区"，做电源的人会以为你想烧管子。**
> 为了不混淆，工程上一般**不说"饱和区"**，而是说：
> - **"完全导通" / "充分导通"** → 对应可变电阻区
> - **"工作在放大区/恒流区"** → 对应饱和区

### 3.3 做开关必须"充分导通"

**目标**：让 MOS 工作在**可变电阻区**，此时它像一个很小的电阻 $R_{DS(on)}$。

**怎么保证？**

$$V_{GS} \gg V_{GS(th)}$$

**经验法则**：
- 数据手册给出 $R_{DS(on)}$ 的**测试条件**（如 $V_{GS}=10\text{ V}$ 或 $4.5\text{ V}$）
- **你的实际驱动电压必须 ≥ 这个测试条件**
- 想要充分导通，一般让 $V_{GS}$ 达到 $V_{GS(th)}$ 的 **3~4 倍**

**举例（重要）：**

| 管子类型 | $V_{GS(th)}$ | 手册标 $R_{DS(on)}$ 的条件 | 用 3.3 V 驱动行不行 |
|---|---|---|---|
| 标准 MOS（如 IRF540N） | 2.0~4.0 V | $V_{GS}=10\text{ V}$ | ❌ **完全不行** |
| 逻辑电平 MOS（如 AO3400、FQP30N06L） | 1.0~2.5 V | $V_{GS}=4.5\text{ V}$（有的还标 2.5 V） | ✅ 4.5 V 可以；3.3 V 要查曲线 |

> ▲ **选型铁律：3.3 V 单片机驱动，必须选"逻辑电平（Logic Level）"MOS，或加栅极驱动 IC。**
> 这一条能救你无数次。L2 实验会亲手验证它。

## 4. 关键参数（重点）★必学

### 4.1 拿到 datasheet 先看这 6 个

| 参数 | 含义 | 选型要求 |
|---|---|---|
| $V_{DS}$ | 漏源击穿电压 | ≥ 工作电压 × **2~3**（感性负载取大值，因为尖峰） |
| $I_D$ | 最大漏极电流 | ≥ 工作电流 × 1.5~2（**注意是按温度降额后的值**） |
| $R_{DS(on)}$ | 导通电阻 | 越低越好；**必须看它的 $V_{GS}$ 测试条件** |
| $V_{GS(th)}$ | 开启阈值 | 决定驱动电压需求 |
| $Q_g$ | 栅极总电荷 | 决定驱动电流和开关速度 |
| $R_{th(j-a)}$ / $R_{th(j-c)}$ | 热阻 | **算结温用，比 $I_D$ 更重要** |

### 4.2 $R_{DS(on)}$ 的三个陷阱 ★必学

**陷阱 1：和 $V_{GS}$ 强相关**

同一个管子，不同 $V_{GS}$ 下 $R_{DS(on)}$ 能差好几倍：

| $V_{GS}$ | 相对 $R_{DS(on)}$（示意） |
|---|---|
| 10 V | 1× （手册标称值） |
| 4.5 V | 1.3~2× |
| 3.3 V | 3~10× 甚至导通不充分 |

**陷阱 2：正温度系数**

$$R_{DS(on)}(T_j) \approx R_{DS(on),25°C}\times\left[1+k(T_j-25)\right]$$

- $k$ 约 **0.4%~0.8% / °C**（要看手册曲线）
- **100°C 时约是 25°C 的 1.5~2 倍**
- **热设计必须用"热态电阻"算，用 25°C 的值算会严重低估发热**

> **好消息**：正温度系数意味着**温度高的管子电阻大、电流小**，会自动均流。
> **所以 MOS 管可以并联**（三极管是负温度系数，并联会热失控）。

**陷阱 3：不是所有管子都便宜又低阻**

高压 MOS 的 $R_{DS(on)}$ 明显更大。$R_{DS(on)}$ 大致按 $V_{DS}^{2.4\sim2.6}$ 增长。
→ **不要盲目选高耐压管子**，够用就行（一般取工作电压 2~3 倍）。

### 4.3 动态参数

| 参数 | 含义 | 影响 |
|---|---|---|
| $Q_g$ 总栅电荷 | 把栅极充到目标电压需要的电荷量 | 驱动电流、开关损耗 |
| $Q_{gs}$ 栅源电荷 | 到米勒平台前的电荷 | |
| $Q_{gd}$ 米勒电荷 | **决定米勒平台长度** | **开关损耗的主要来源** |
| $C_{iss}=C_{gs}+C_{gd}$ | 输入电容 | 驱动能力需求 |
| $C_{oss}$ | 输出电容 | 关断时的谐振/损耗 |
| $C_{rss}=C_{gd}$ | 反向传输电容 | 米勒效应 |
| $t_r / t_f$ | 上升/下降时间 | 开关损耗 |
| $t_{d(on)}/t_{d(off)}$ | 开通/关断延迟 | |

### 4.4 极限与热参数

| 参数 | 说明 |
|---|---|
| $V_{GS(max)}$ | **通常 ±20 V，超过就击穿栅氧（不可逆！）** |
| $P_D$ | 最大功耗，**注意标的是 $T_c=25°C$ 的理想值** |
| $T_j$ | 结温，一般上限 150°C（有的 175°C） |
| $R_{th(j-c)}$ | 结到壳热阻（决定散热片需求） |
| $R_{th(j-a)}$ | 结到环境热阻（**不装散热片时用这个**） |
| $E_{AS}$ | 雪崩能量（感性负载关断时的重要指标） |

> ▲ **为什么 $I_D$ 这个参数最不能信**：
> 手册标的 $I_D$ 通常是"结温 25°C、壳温 25°C"的理想值。真实可承受电流由**热**决定：
> $$I_{max}\approx\sqrt{\frac{T_{j,max}-T_a}{R_{DS(on),hot}\cdot R_{th(j-a)}}}$$
> 一个标 $I_D=100\text{ A}$ 的管子，实际可能只能过 5~10 A。

## 5. 栅极驱动（今天的核心）★★★

> **这一节是 MOS 管学习的真正门槛。** 前面都是"知道"，这一节是"会用"。

### 5.1 为什么栅极驱动这么重要

MOS 管是**电压控制**器件，但这只对**稳态**成立。

**动态过程是这样的：**
1. 栅极是一个电容 $C_{iss}$（几百 pF ~ 几十 nF）
2. 每次开关都要给这个电容充/放电
3. 电荷量就是 $Q_g$（几 nC ~ 几百 nC）
4. 所需电流：$I_{drive}=\dfrac{Q_g}{t_{switch}}$
5. **如果驱动电流不够，开关就慢 → 开关损耗大 → 发热 → 烧管**

**所以**：MOS 管虽然稳态不耗栅极电流，但**开关瞬间需要一个很大的脉冲电流**。

### 5.2 米勒平台（Miller Plateau）★必学

**给栅极充电时，$V_{GS}$ 的变化不是一条直线，而是有一段"平台"：**

```
  Vgs
   │
12V├───────────────┐
   │               │
   │          ┌────┘  ← 米勒平台
   │         ╱       │
   │       ╱         │
Vth├─────╱           │
   │   ╱             │
  0└───┴──────┴──────┴────→ t
     t1   平台     t2
       (Qgs)  (Qgd)
```

**三个阶段：**

| 阶段 | 栅极充的电荷 | 发生了什么 |
|---|---|---|
| 1. 充到 $V_{GS(th)}$ | $Q_{gs}$ | MOS 开始导通，$I_D$ 上升 |
| 2. **米勒平台** | **$Q_{gd}$** | **$V_{GS}$ 几乎不变**，但 $V_{DS}$ 快速下降 → **这里是开关损耗的主要发生地** |
| 3. 充到驱动电压 | 剩余电荷 | 沟道完全打开，$R_{DS(on)}$ 降到最低 |

**为什么会有平台？**
在第二阶段，$V_{DS}$ 快速变化，通过 $C_{gd}$ 耦合到栅极，把充进来的电荷"吸走"了 —— 这就是**米勒效应**。栅极电流全部被用来"对付"这个耦合，$V_{GS}$ 就停住了。

**工程意义：**
- **平台越长 = 开关越慢 = 开关损耗越大**
- 平台长度由 $Q_{gd}$ 决定 → **选管子时 $Q_{gd}$ 比 $C_{iss}$ 更值得关注**
- **要缩短平台，只有加大驱动电流**

### 5.3 开关损耗计算

**开通 + 关断损耗（近似）：**
$$P_{sw}\approx\frac{1}{2}V_{DS}\cdot I_D\cdot(t_r+t_f)\cdot f_{sw}$$

**关键洞察：**

$$P_{sw}\propto f_{sw}$$

- **PWM 频率越高，开关损耗越大**（成正比！）
- 而导通损耗 $P_{cond}=I_D^2 R_{DS(on)}$ 与频率无关
- **所以存在一个"效率最优点"频率**：太低则纹波大、体积大；太高则开关损耗爆炸

**总损耗：**
$$P_{total}=P_{cond}+P_{sw}+P_{gate}+P_{rr}$$

| 损耗项 | 公式 | 说明 |
|---|---|---|
| 导通损耗 | $I_D^2\cdot R_{DS(on),hot}$ | 与电流平方成正比 |
| 开关损耗 | $\frac{1}{2}V_{DS}I_D(t_r+t_f)f_{sw}$ | 与频率成正比 |
| 栅极驱动损耗 | $Q_g\cdot V_{GS}\cdot f_{sw}$ | 通常较小 |
| 体二极管反向恢复 | — | 半桥/同步整流时显著 |

### 5.4 栅极电阻 $R_g$ ★必学

**用途**：限制栅极充放电的峰值电流，控制开关速度。

$$I_{peak}\approx\frac{V_{drive}}{R_g+R_{driver,内部}}$$

**取值权衡（这是设计的艺术）：**

| $R_g$ 太小 | $R_g$ 太大 |
|---|---|
| 开关快 → 开关损耗小 | 开关慢 → 开关损耗大、发热 |
| 但 **dV/dt 大 → 振铃、EMI、可能误开通** | 但波形干净、EMI 好 |
| 栅极电流可能超过驱动 IC 能力 | |

**经验值**：**几 Ω ~ 几十 Ω**，常用 **10 Ω**。

**进阶技巧：**
- **非对称驱动**：开通用一个电阻，关断并联一个二极管 + 更小的电阻（关断更快，减少死区损耗）
- **栅极电阻要靠近栅极**放置

### 5.5 栅极驱动电路的几种做法

#### （1）单片机 IO 直驱（仅限逻辑电平 MOS + 小电流）

```
IO ──[Rg 10Ω]── G
                │
              [Rpd 10kΩ]  ← 必须有！
                │
               GND
```

**要求**：逻辑电平 MOS、$Q_g$ 小（几 nC）、开关频率低。
**问题**：IO 输出电流有限（通常 20 mA 以内），开关会慢。

> ▲ **$R_{pd}$（栅源下拉）是必须的！** 因为单片机复位期间 IO 是高阻态，栅极悬空时 $C_{iss}$ 上的电荷无处泄放，MOS 会**保持误导通** → 上电就转/就亮，非常危险。

#### （2）三极管推挽驱动

```
        VCC
         │
        ┌┴┐ PNP
   ┌────┤ ├────┐
   │    └┬┘    │
IO─┤     │     ├──[Rg]── G
   │    ┌┴┐    │
   └────┤ ├────┘
        └┬┘ NPN
         │
        GND
```

**原理**：IO 高 → NPN 导通 → 快速拉低；IO 低 → PNP 导通 → 快速拉高。
能提供几百 mA 的峰值电流，速度快得多。

#### （3）专用栅极驱动 IC（推荐）

| 类型 | 典型芯片 | 用途 |
|---|---|---|
| 低边驱动 | TC4427、UCC27517、IR2110（低边部分） | 单管驱动 |
| 半桥驱动 | IR2104、IR2110、EG2133 | 带自举，驱动上下管 |
| 隔离驱动 | 光耦驱动、变压器驱动 | 高压隔离 |

**优点**：峰值电流大（1~4 A）、自带死区、自带自举、保护功能。

### 5.6 自举电路（高边 N 沟道驱动）☆进阶

**问题**：N 沟道做高边开关时，源极电位接近 $V_{CC}$，要让 $V_{GS}>10\text{ V}$，栅极就得比 $V_{CC}$ 还高 —— 需要一个"浮动的电源"。

**方案：自举电容**

```
        VCC ──────────────┬──────── D
                          │
                    ┌─────┴─────┐
                    │  高边 MOS  │
       ┌────────────┤           │
       │            └─────┬─────┘
   ┌───┴───┐              │
   │ 自举  │              ├──── 输出
   │ 二极管│              │
   └───┬───┘        ┌─────┴─────┐
       │            │  低边 MOS  │
   ┌───┴───┐        └─────┬─────┘
   │ 自举  │              │
   │ 电容  │             GND
   └───┬───┘
       └──── 驱动 IC 的 VB 脚
```

**工作原理**：
1. 低边导通时，输出被拉到 GND
2. 自举电容通过自举二极管从 $V_{CC}$ 充电到约 $V_{CC}-0.7\text{ V}$
3. 低边关断、高边要开通时，电容"浮"在高边源极上
4. 电容电压叠加源极电位，给栅极提供 $V_{CC}$ 以上的驱动电压

**设计要点：**
- 自举电容：**0.1~1 µF**（要足够大，能提供 $Q_g$ 还要留余量）
- 自举二极管：**快恢复或肖特基**（普通二极管反向恢复慢，会失效）
- **占空比 100% 时自举电容无法充电** → 需要"刷新"（定期关断高边）
- 或者用**电荷泵**做 100% 占空比场景

### 5.7 死区时间（半桥必备）★必学

**上管和下管绝对不能同时导通**，否则 $V_{CC}$ 直接对地短路 → **瞬间炸管（Shoot-through）**。

**估算短路电流**：$I=\dfrac{V_{CC}}{R_{DS(on),上}+R_{DS(on),下}}$

**例**：12 V 母线，两个 20 mΩ 的管子
$$I=\frac{12}{0.04}=300\text{ A}$$

→ 远远超过管子能力，**微秒级就能炸**。

**死区时间（Dead Time）**：在切换上下管之间插入的"都不导通"的时间。

| 死区太短 | 死区太长 |
|---|---|
| 有直通风险 | 体二极管导通时间长 → 损耗大 |

**常用值**：**100 ns ~ 1 µs**（取决于驱动能力和管子速度）。

**注意**：死区期间，感性负载的电流**通过体二极管续流** → 体二极管的反向恢复特性变得重要。

## 6. 损耗与热设计 ★必学

### 6.1 热阻模型（把热当电路算）

**热路 = 电路，这是最有效的理解方式：**

| 电学量 | 热学量 |
|---|---|
| 电压 $U$ | 温差 $\Delta T$（°C） |
| 电流 $I$ | 功耗 $P$（W） |
| 电阻 $R$ | **热阻 $R_{th}$（°C/W）** |
| 电容 | 热容（决定升温快慢） |

$$\Delta T = P\times R_{th}$$

**热阻链条（串联）：**
$$R_{th(j-a)} = R_{th(j-c)} + R_{th(c-s)} + R_{th(s-a)}$$

- $R_{th(j-c)}$：结到壳（管子本身，查手册）
- $R_{th(c-s)}$：壳到散热片（绝缘垫/硅脂，约 0.5~2 °C/W）
- $R_{th(s-a)}$：散热片到环境（散热片规格）

### 6.2 完整热设计步骤（背下来）★

**五步走：**

1. **确定最坏工作电流** $I_D$（不是平均电流，是峰值或最大持续电流）
2. **查热态 $R_{DS(on)}$**：按目标 $T_j$（如 100°C）从手册曲线取，或估算为 25°C 值的 1.5~2 倍
3. **算功耗** $P=I_D^2\cdot R_{DS(on),hot}$
4. **算允许热阻** $R_{th(允许)}=\dfrac{T_{j,max}-T_a}{P}$
5. **对比实际热阻**：实际 $R_{th(j-a)}$ 必须小于允许值，否则加散热片/换管子

### 6.3 完整算例

**条件**：$V_{CC}=12\text{ V}$，负载 $R_L=4\ \Omega$，管子 $R_{DS(on),25°C}=50\text{ m}\Omega$，$R_{th(j-a)}=62\text{ °C/W}$（TO-220 不装散热片），$T_a=25\text{ °C}$，$T_{j,max}=150\text{ °C}$

**① 工作电流**
$$I_D=\frac{12}{4+0.05}\approx2.96\text{ A}$$

**② 热态电阻**（假设 $T_j=100\text{ °C}$，取 1.6 倍）
$$R_{DS(on),hot}=0.05\times1.6=0.08\ \Omega$$

**③ 功耗**
$$P=I_D^2\times R=2.96^2\times0.08=0.70\text{ W}$$

**④ 结温**
$$T_j=T_a+P\times R_{th(j-a)}=25+0.70\times62=68.4\text{ °C}$$

**⑤ 结论**：$68.4\text{ °C}<150\text{ °C}$，**安全**。

**但如果驱动不充分**，$R_{DS(on)}$ 变成 $0.5\ \Omega$：
$$P=2.96^2\times0.5=4.4\text{ W}\quad\Rightarrow\quad T_j=25+4.4\times62=298\text{ °C}$$

**→ 远远超过 150°C，必烧。**

> ▲ **这个对比就是"栅极驱动为什么重要"的定量答案。**

### 6.4 散热手段

| 手段 | 效果 |
|---|---|
| 铺铜 + 过孔阵列 | 贴片 MOS 的主要散热路径，过孔越多越好 |
| 散热片 | TO-220/TO-247 常用 |
| 硅脂 | 填充微观空隙，降低 $R_{th(c-s)}$ |
| 绝缘垫 | 需要电气隔离时用，但会增加热阻 |
| 增大封装 | DPAK/D2PAK 比 SOT-23 散热好得多 |
| 降额使用 | 最有效也最省事 |

## 7. 典型电路

### 7.1 低边开关（最常用）★

```
        VCC
         │
       [负载]   ← 电机/LED灯带/加热丝
         │
         D
         │
   G ────┤  N-MOS
         │
         S
         │
        GND

  IO ──[Rg]── G
              │
            [Rpd 10k]
              │
             GND
```

| 元件 | 作用 | 典型值 |
|---|---|---|
| $R_g$ | 限制栅极峰值电流、抑制振铃 | 10~100 Ω |
| $R_{pd}$ | 防止悬空误导通 | 10 kΩ |
| 续流二极管 | 感性负载时保护（**若负载是感性，必加**） | 肖特基 |

**优点**：驱动简单（源极接地，栅极用普通电压就能驱动）
**缺点**：负载不接地（不能与系统共地）

### 7.2 高边开关

**方案 A：P 沟道（简单）**

```
        VCC
         │
         S
         │
   G ────┤  P-MOS
         │
         D
         │
       [负载]
         │
        GND
```

- 栅极拉低（到 GND）时导通，通过三极管/NMOS 拉低
- **注意 $V_{GS}$ 不能超过 ±20 V**：$V_{CC}$ 高时要加分压或齐纳钳位

**方案 B：N 沟道 + 自举（性能好）** → 见 5.6

**选择逻辑**：
- 低电压（<20 V）、电流不大 → **P 沟道简单省事**
- 高电压、大电流 → **N 沟道 + 驱动 IC**（因为 N 沟道 $R_{DS(on)}$ 低得多）

### 7.3 半桥 / H 桥 ★

```
        VCC
     ┌───┴───┐
     │ 上管  │  ← 高边 N-MOS
     └───┬───┘
         ├────── 输出（接电机一端）
     ┌───┴───┐
     │ 下管  │  ← 低边 N-MOS
     └───┬───┘
        GND
```

**H 桥 = 两个半桥**，可以正反转。

**必备要素：**
- [ ] 死区时间
- [ ] 自举电路（高边驱动）
- [ ] 母线电容（吸收换流尖峰）
- [ ] 栅极电阻
- [ ] 栅源下拉
- [ ] 过流保护 / 温度保护

### 7.4 防反接（P-MOS）

串联二极管有 $V_F$ 损耗；用 P-MOS 反接更省：

```
   输入+ ──── S ┌──────┐ D ──── 输出+
               │ P-MOS│
   输入− ──────┤ G    │
               └──────┘
```

正常时体二极管先导通，然后沟道导通把压降降到 $I\cdot R_{DS(on)}$。

### 7.5 PWM 调速（比赛最常用）

**低边 PWM + 续流二极管**是直流电机调速的最简方案：

```
        VCC
         │
       [电机]
         │
         ├──────┤◁├──────┐   ← 续流二极管（阴极接 VCC 侧）
         │               │
         D               │
         │               │
   G ────┤ N-MOS         │
         │               │
         S               │
         │               │
        GND ─────────────┘
```

**PWM 频率选择：**
- 太低（<1 kHz）：有啸叫、电流脉动大
- 太高（>50 kHz）：开关损耗大、驱动要求高
- **常用 1~20 kHz**（电机）；LED 调光用 >1 kHz（避免可见闪烁）

**占空比与转速**：平均电压 $=D\times V_{CC}$，近似线性调速。

## 8. 七大死法与排查 ★必学

| # | 死法 | 现象 | 预防 |
|---|---|---|---|
| 1 | **栅极驱动不足** | 管子发烫、带不动负载 | 用逻辑电平 MOS 或驱动 IC；查 $R_{DS(on)}$ 的 $V_{GS}$ 条件 |
| 2 | **上下管直通** | 一上电就炸、有爆响 | 加死区；用带死区的驱动 IC |
| 3 | **$V_{DS}$ 尖峰超限** | 随机损坏、无明显规律 | 续流二极管、RC 吸收、母线电容、提高耐压裕量 |
| 4 | **散热不足** | 热、逐渐失效、焊点变色 | 按热设计五步验算；铺铜、散热片 |
| 5 | **栅极悬空误导通** | 上电即导通、不受控 | **必加栅源下拉电阻** |
| 6 | **寄生振荡／栅极振荡** | 波形有振铃、EMI 超标、随机炸管 | 栅极电阻、缩短栅极走线、减小功率回路面积 |
| 7 | **静电击穿栅氧** | 拿起来就是坏的 | 防静电台垫、先放电、别裸手摸引脚 |

**排查顺序（上电不工作时）：**

1. **先量栅极电压**：有没有到驱动电压？没到 → 驱动问题
2. **量 $V_{DS}$**：导通时应该是 $I\times R_{DS(on)}$（几十 mV~几百 mV）。如果是几伏 → 导通不充分
3. **量栅极波形**（有示波器）：看有没有平台、有没有振铃
4. **断电量体二极管**：坏了的话体二极管通常也短路
5. **查负载和续流路径**：感性负载有没有续流？

# 第 2 部分 实践

## L0 上电前的安全规程（先看这个）★

> **做实验前必须读一遍。** 这几条能帮你省下买管子的钱。

**装备要求：**
- [ ] **直流稳压电源，并且会设限流**（最重要！先设 0.1~0.5 A）
- [ ] 万用表
- [ ] 面包板或洞洞板
- [ ] 手边不要有金属杂物（防止短路）
- [ ] 焊接/接触 MOS 前先摸一下接地的金属放静电

**六条铁律：**

1. **先接线，后上电。改接线前先断电。**
2. **上电前先用万用表量 $V_{CC}$ 和 GND 之间有没有短路**（电阻档，不是通断档）
3. **限流从小往大开**：先 0.1 A，正常工作再逐步加
4. **第一次上电用手指背轻碰管子**（不是手心抓）—— 发烫立刻断电
5. **不要超过 $V_{GS}$ 的 ±20 V**
6. **拆下来的 MOS 放防静电袋**，别随手扔桌上

## L1 万用表级实验（只有万用表也能做）

> **门槛**：万用表 + 直流电源（或 9 V 电池）+ 面包板 + 几个电阻 + 一个 MOS 管
> **耗时**：约 1.5 小时
> **完成标准**：E1、E2、E3 全部做完并填表

### E1 用万用表判断 MOS 管好坏与引脚 ★

**目标**：掌握"体二极管法"识别 D/S，并判断管子是否已损坏。

**待测管子**：任意 N 沟道 MOS（如 IRF540N、AO3400、FQP30N06L）

**步骤：**

1. 万用表打到**二极管档**
2. 三个引脚两两组合测量，**共 6 次**（红黑各换一次），记录读数
3. 找出**唯一一次正向导通（0.3~0.7 V）、反向不通（OL）**的那一对 —— 那就是 **S 和 D 之间的体二极管**

**记录表：**

| 红表笔 | 黑表笔 | 读数（V 或 OL） | 判断 |
|---|---|---|---|
| 脚1 | 脚2 | | |
| 脚2 | 脚1 | | |
| 脚1 | 脚3 | | |
| 脚3 | 脚1 | | |
| 脚2 | 脚3 | | |
| 脚3 | 脚2 | | |

**结论填写：**

- 体二极管在 \_\_\_ 脚和 \_\_\_ 脚之间
- **导通时红表笔接的是 \_\_\_ 脚** → 那就是 \_\_\_ 极（N 沟道体二极管阳极在 S）
- 剩下那个脚是 \_\_\_ 极
- 栅极与另外两脚之间应该都是 \_\_\_（OL / 有读数）

**判废标准：**

| 现象 | 结论 |
|---|---|
| 体二极管正反都通 | ❌ **击穿，报废** |
| 体二极管正反都不通 | ❌ **开路，报废** |
| 栅极与 S 或 D 之间导通 | ❌ **栅氧击穿，报废** |
| 符合"一个方向导通、其余全不通" | ✅ 基本正常 |

> ▲ **注意**：万用表判断不了"参数变差"（如 $R_{DS(on)}$ 变大、栅极漏电）。**能过这一关只说明没死透。**

### E2 实测开启阈值电压 $V_{GS(th)}$ ★

**目标**：亲眼看到"阈值电压"是什么，并和手册对比。

**电路：**

```
        +5V
         │
        [R1 1kΩ]   ← 限流保护
         │
         ├────── 万用表红表笔（量 Vgs）
         │
         G
         │
     [电位器 10kΩ]
      ┌──┴──┐
      │     │
     +5V   GND
     
     D ──── VCC(+5V)
     S ──── GND
```

**更好的做法**（避免电位器接触不良）：

```
     +5V ──[10kΩ]──┬── G
                   │
                 [10kΩ 电位器]
                   │
                  GND

     D ── +5V (通过电流表或串联电阻)
     S ── GND
```

**步骤：**

1. 电位器从 0 慢慢往上调
2. **万用表一边量 $V_{GS}$**，一边用另一个表（或看电源电流）**监测 $I_D$**
3. 记录**刚开始出现电流时的 $V_{GS}$** → 这就是 $V_{GS(th)}$
4. 查你的管子手册的 $V_{GS(th)}$ 范围（如 2.0~4.0 V）

**记录：**

| 项目 | 你的测量值 | 手册值 |
|---|---|---|
| $V_{GS(th)}$（$I_D$ 开始明显上升） | | |
| 手册给的 $V_{GS(th)}$ 范围 | — | |

**分析题：**
1. 你的测量值落在手册范围内吗？
2. 手册的 $V_{GS(th)}$ 测试条件是什么（$I_D$ 多少、$V_{DS}$ 多少）？这解释了为什么你的测量值有偏差吗？
3. **如果用手册的 $V_{GS(th)}$ 作为"驱动电压"，会有什么问题？**

### E3 实测 $R_{DS(on)}$，并证明"驱动电压决定一切" ★★★

> **这是今天最重要的一个实验。** 它用数字说服你"为什么必须充分导通"。

**电路：**

## A 卷答案

### A1（5 分）

```
        D
        │
   G ───┤  ┌──|<|──┐
        │  │       │     ← 体二极管
        │  └───────┘       阳极在 S，阴极在 D
        │
        S
```

**得分点**：
- 符号正确画出（三条沟道线、箭头指向沟道内）（2 分）
- G/D/S 标注正确（1 分）
- 体二极管方向 S→D 正确（1 分）
- 解释：衬底为 P 型并与源极 S 短接，漏区为 N+，二者构成 PN 结，**阳极在 P 侧（S），阴极在 N 侧（D）**（1 分）

### A2（5 分）

- 栅极与沟道之间是 **SiO₂ 绝缘层**，稳态时没有电流通路，所以**静态**几乎不耗电。
- 但栅极结构本质上是一个**电容 $C_{iss}$**（由 $C_{gs}$、$C_{gd}$ 组成）。
- 每次开关都要把这个电容从 0 充到驱动电压（或反过来放电），需要搬运的电荷量就是 **$Q_g$**。
- 所需电流 $I=Q_g/t_{switch}$。如果 $t_{switch}$ 要求很短（如 100 ns），而 $Q_g=30\text{ nC}$，就需要 **300 mA** 的脉冲电流。
- **结论**：MOS 管"静态不耗电、动态很吃电流"。驱动能力不足 → 开关慢 → 米勒平台长 → 开关损耗大 → 发热。

### A3（6 分）

- **BJT 的饱和区**：$V_{CE}$ 很小（0.1~0.3 V），两个结都正偏，$I_C$ 由外电路决定。管子**像闭合的开关**，导通最好。**做开关要用饱和区。**（2 分）
- **MOS 的饱和区**：$V_{DS}>V_{GS}-V_{GS(th)}$，沟道在漏端夹断，$I_D$ 主要由 $V_{GS}$ 决定、几乎不随 $V_{DS}$ 变。管子**像恒流源**，导通很差。**做开关绝不能用这个区。**（2 分）
- **MOS 做开关要用"可变电阻区（线性区）"**，此时 $V_{DS}<V_{GS}-V_{GS(th)}$，管子表现为小电阻 $R_{DS(on)}$。（1 分）
- 为避免混淆，工程上说 **"完全导通 / 充分导通"** 和 **"工作在恒流区/放大区"**，而不说"饱和区"。（1 分）

> **这是本题最重要的知识点。如果你的答案把两个"饱和"搞反了，说明这一块必须重看第 3.2 节。**

### A4（5 分）

- **米勒平台**：在栅极充电过程中，$V_{GS}$ 上升到某个电压后**停止上升、维持一段时间的现象**。（1 分）
- **发生阶段**：MOS 开始导通后、$V_{DS}$ 快速下降的那个阶段（第二阶段）。（1 分）
- **原因**：$V_{DS}$ 快速变化通过米勒电容 $C_{gd}$ 耦合到栅极，把驱动电流"吸走"，所以 $V_{GS}$ 停住。（1 分）
- **为什么是主要损耗来源**：这一阶段**电流已经建立（$I_D$ 大）、电压还没降下来（$V_{DS}$ 大）**，$P=V\cdot I$ 同时很大 → 瞬时功率极高。（1 分）
- **缩短方法**：加大驱动电流（降低 $R_g$、用驱动 IC）、选 $Q_{gd}$ 小的管子。（1 分）

### A5（5 分）

- **作用**：给栅极提供确定电位（默认关断）；**泄放 $C_{iss}$ 上积累的电荷**。（2 分）
- **不装的后果**：栅极悬空时电位不确定，$C_{iss}$ 上的电荷无处泄放，MOS 会**保持导通或随机导通**。（1 分）
- **危险场景**：
  - **上电瞬间**：单片机复位期间 IO 是高阻态，栅极悬空 → MOS 误导通 → **电机在程序还没跑起来时就全速转起来**，可能撞坏机械结构或伤人
  - **热插拔/干扰**：栅极受干扰耦合积累电荷 → 误导通
  - **静电**：悬空栅极更容易被静电击穿（1~2 分）

### A6（7 分）

- **死区时间**：在上下管切换时，故意插入的一段**两个管子都不导通**的时间。（1 分）
- **为什么必须加**：MOS 关断需要时间（$t_{d(off)}+t_f$）。如果上管还没完全关断就开下管，两个管子会**同时导通**，$V_{CC}$ 直接对地短路 → 产生极大电流（可达数百安培）→ **瞬间炸管**（Shoot-through）。（3 分）
- **死区期间体二极管导通的问题**：
  - 体二极管是 PN 结，**反向恢复慢（$t_{rr}$ 长）**，换流时会产生**电流尖峰和额外损耗**（1 分）
  - 体二极管 $V_F$（0.7~1.5 V）远大于 MOS 导通压降，**死区越长，这段高损耗时间越长** → 效率下降（1 分）
  - 高频场合需要外并**肖特基**来分担，或优化死区时间（1 分）

### A7（7 分）

| 对比项 | IO 直驱 | 专用驱动 IC |
|---|---|---|
| 峰值电流 | ≤20 mA（很弱） | 1~4 A |
| 开关速度 | 慢（µs 级） | 快（几十~几百 ns） |
| 适用频率 | **很低**（<1 kHz） | 高（几十 kHz~MHz） |
| 适用管子 | **逻辑电平 + 小 $Q_g$** | 任意 |
| 电路复杂度 | 简单 | 需外围元件 |
| 成本 | 低 | 稍高 |
| 保护功能 | 无 | 常带欠压/过流/死区 |

（表格答对给 3 分）

**适用场合**（2 分）：
- IO 直驱：小电流、低频、逻辑电平 MOS（如驱动 LED 灯带、小继电器、小风扇）
- 驱动 IC：大电流、高频 PWM、电机驱动、半桥（必须用 IC 才能做自举和死区）

**IO 直驱的准备**（2 分）：
1. **必须选逻辑电平 MOS**（$R_{DS(on)}$ 标 $V_{GS}=4.5\text{ V}$ 或更低）
2. **必须加栅源下拉电阻**
3. **必须加栅极串阻**（不能直接接 IO，会损坏 IO）
4. 限制开关频率（低频用）
5. 选 $Q_g$ 尽量小的管子（如 AO3400）
6. 加续流二极管（感性负载）

## B 卷答案

### B1（10 分）热设计验算

**① 工作电流**
$$I_D\approx\frac{12}{3}=4\text{ A}$$

**② 热态电阻**
$$R_{DS(on),hot}=0.04\times1.7=0.068\ \Omega$$

**③ 导通功耗**
$$P=I_D^2\cdot R=4^2\times0.068=16\times0.068=1.088\approx1.09\text{ W}$$

**④ 结温**（$T_a=40\text{ °C}$）
$$T_j=40+1.088\times62=40+67.5=107.5\text{ °C}$$

**⑤ 判断**
- $107.5\text{ °C}<150\text{ °C}$ → **安全**，但**余量不大**（约 42°C）
- 环境升到 **60°C** 时：$T_j=60+67.5=127.5\text{ °C}$ → **仍然低于 150°C，但余量只剩 22°C**
  - ⚠️ 考虑到 $R_{DS(on)}$ 会随温度进一步上升（正反馈），**实际会更高** → **接近危险，必须加散热片**

**评分**：每步 2 分（公式 1 分 + 结果 1 分），判断与结论 2 分。

### B2（8 分）栅极驱动电流

**① 所需平均驱动电流**
$$I_{drive}=\frac{Q_g}{t_{switch}}=\frac{30\times10^{-9}}{100\times10^{-9}}=0.3\text{ A}=300\text{ mA}$$

**② 峰值电流**
$$I_{peak}=\frac{V_{drive}}{R_g}=\frac{12}{10}=1.2\text{ A}$$

**够不够？**
- 峰值电流 **1.2 A > 300 mA** → **够**。
- 但要注意：这只是"起点的峰值"。随着 $V_{GS}$ 上升，电流会按指数衰减。
- **更严谨的估算**：用 RC 时间常数，$C_{iss}\approx Q_g/V_{drive}=30\text{ nC}/12\text{ V}=2.5\text{ nF}$
  $$\tau=R_g\cdot C_{iss}=10\times2.5\times10^{-9}=25\text{ ns}$$
  达到 90% 需要约 $2.3\tau\approx58\text{ ns}$ → **满足 100 ns 要求**。（严格算：$2.3\times25=57.5\text{ ns}$）

**评分**：① 3 分；② 峰值 2 分 + 判断 3 分。

### B3（8 分）开关损耗与频率

**① 开关损耗**
$$P_{sw}=\frac{1}{2}V_{DS}I_D(t_r+t_f)f_{sw}=\frac{1}{2}\times24\times2\times(200+150)\times10^{-9}\times f_{sw}$$
$$=24\times350\times10^{-9}\times f_{sw}=8.4\times10^{-6}\times f_{sw}$$

- $f_{sw}=1\text{ kHz}$：$P_{sw}=8.4\times10^{-6}\times1000=8.4\times10^{-3}=8.4\text{ mW}$
- $f_{sw}=20\text{ kHz}$：$P_{sw}=8.4\times10^{-6}\times20000=0.168\text{ W}=168\text{ mW}$

**② 导通损耗**（与频率**无关**，因为 MOS 导通时一直是这个损耗）
$$P_{cond}=I_D^2\cdot R_{DS(on),hot}=2^2\times0.06=4\times0.06=0.24\text{ W}$$

**③ 总损耗**
- 1 kHz：$0.24+0.0084=0.248\text{ W}$
- 20 kHz：$0.24+0.168=0.408\text{ W}$

**④ 倍数**
$$\frac{0.408}{0.248}\approx1.64\text{ 倍}$$

**说明**：开关损耗**与频率成正比**，而导通损耗与频率无关。
- 频率提高 20 倍，开关损耗也提高 20 倍（8.4 mW → 168 mW）
- 但由于此时导通损耗占主导，总损耗只增加 1.65 倍
- **结论**：**当开关损耗开始超过导通损耗时，继续提高频率就得不偿失了**。这就是"存在最优开关频率"的原因。如果电流更大、管子 $R_{DS(on)}$ 更小，导通损耗占比下降，频率对总损耗的影响会更剧烈。

**评分**：① 3 分；② 2 分；③ 1 分；④ 结论 2 分。

### B4（7 分）死区与直通

**① 峰值电流**
$$I=\frac{V_{CC}}{R_{上}+R_{下}}=\frac{24}{0.015+0.015}=\frac{24}{0.03}=800\text{ A}$$

**② 瞬时功率**
$$P=V_{CC}\times I=24\times800=19200\text{ W}\approx19.2\text{ kW}$$

**③ 能量**
$$E=P\times t=19200\times2\times10^{-6}=0.0384\text{ J}=38.4\text{ mJ}$$

**④ 会不会损坏？**
**几乎必然损坏。** 理由：
- 一般 TO-220 功率 MOS 的**雪崩能量 $E_{AS}$ 只有几十~几百 mJ**，而且在 800 A 这种远超额定的电流下，管子内部会发生**电流集中 / 寄生三极管（BJT）触发**，实际耐受能力远低于标称 $E_{AS}$
- 实际电路中还有母线电容、走线电感，真实电流冲击会更大，并且伴随剧烈振荡
- **实践中 2 µs 的直通几乎必然炸管**，即使侥幸存活也会参数劣化

**结论**：这就是为什么**死区时间和驱动时序必须严格保证**，也是为什么实际电路要加**过流保护**（如采样电阻 + 比较器快速关断、驱动 IC 的 DESAT 检测）。

**评分**：①②③ 各 1.5 分；④ 2.5 分。

### B5（7 分）驱动电路设计

**① 可行吗？**
**不可行。** 因为 **N 沟道 MOS 做高边开关时，源极电位接近 12 V**。要让 $V_{GS}>4.5\text{ V}$，栅极电压必须高于源极，也就是要 **>16.5 V**。而单片机 IO 只有 3.3 V，**根本不可能**给出足够驱动电压。
（另外，即使强行驱动，源极电位会随负载变化，$V_{GS}$ 不稳定。）

> **要点**：**N 沟道做高边必须用自举电路或电荷泵 + 驱动 IC**，或者改用 **P 沟道**。

**② 改成低边开关的电路**

```
   12V ──[负载 1A]──┬── D
                    │
              G ────┤ N-MOS（逻辑电平）
                    │
                    S
                    │
                   GND

   IO ──[Rg]──┬── G
              │
            [Rpd 10kΩ]
              │
             GND
```

**元件**：$R_g$（栅极串阻）、$R_{pd}$（栅源下拉 10 kΩ）、（感性负载再加**续流二极管**）

**③ $R_g$ 取值范围**
- **下限（为什么不能太小）**：峰值电流 $I_{peak}=V_{drive}/R_g$ 不能超过 IO 的最大输出电流 20 mA
  $$R_g\ge\frac{3.3}{0.02}=165\ \Omega$$
  所以 **$R_g\ge165\ \Omega$**（实际上还要更大，因为 IO 拉/灌电流不对称）
- **上限（为什么不能太大）**：$R_g$ 太大 → 开关太慢 → 开关损耗大
  $$\tau=R_g C_{iss},\quad C_{iss}\approx Q_g/V_{drive}=8\text{ nC}/3.3\text{ V}\approx2.4\text{ nF}$$
  若要求开关时间 < 5 µs，则 $\tau<2.2\text{ µs}$ → $R_g<900\ \Omega$
- **结论**：**约 200 Ω ~ 1 kΩ**，推荐 **470 Ω~1 kΩ**（速度不是重点，安全是）

**④ IO 直驱的开关时间**
$$t=\frac{Q_g}{I_{IO}}=\frac{8\times10^{-9}}{0.02}=4\times10^{-7}\text{ s}=400\text{ ns}$$

（这是理想估算；实际因为 IO 电压随充电上升、电流下降，会更慢，大约 1~2 µs。）

**评分**：① 2 分；② 2 分；③ 2 分；④ 1 分。

## C 卷答案

### C1（10 分）

**① 根本原因**
IRF540N 是**标准 MOS**，手册的 $R_{DS(on)}=44\text{ m}\Omega$ 是在 **$V_{GS}=10\text{ V}$** 条件下测的。它的 $V_{GS(th)}$ 范围是 2.0~4.0 V，**3.3 V 只是刚刚超过阈值**，管子处于**"半开"状态**——既不是完全导通，也不在截止。

实测 $V_{DS}=1.2\text{ V}$ 就是铁证：如果充分导通，$V_{DS}$ 应该是 $I\cdot R_{DS(on)}\approx2\times0.044=88\text{ mV}$ 量级。

**② 实际 $R_{DS(on)}$ 和功耗**

由 $V_{DS}=1.2\text{ V}$、$I\approx2\text{ A}$：
$$R_{DS(on),实际}=\frac{1.2}{2}=0.6\ \Omega$$

**是手册值的 13.6 倍**（$0.6/0.044$）。

功耗：
$$P=I^2R=2^2\times0.6=2.4\text{ W}$$

再算结温（TO-220 无散热片 $R_{th(j-a)}\approx62\text{ °C/W}$）：
$$T_j=25+2.4\times62=173.8\text{ °C}$$

**超过 150°C 上限 → 几秒钟就烫得不能碰，持续下去必烧。**

**③ 解决方案（至少两种）**

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **换逻辑电平 MOS** | 用 AO3400、FQP30N06L、IRLZ44N 等 | 最简单、成本最低 | 需要重新选型/采购 |
| **加栅极驱动 IC** | 低边用 TC4427 等 | 驱动能力强、速度快 | 增加元件和成本 |
| **提高驱动电压** | 用 10~12 V 驱动栅极（需电平转换） | 保留原管子 | 需要额外电源和电平转换 |
| **三极管推挽升压驱动** | 用 NPN/PNP 组成推挽，把 3.3 V 信号变成 12 V 驱动 | 元件便宜、可得 | 电路复杂、速度不如专用 IC |
| **改用 P 沟道高边** | 若允许改拓扑 | 高边驱动简单 | P 沟道 $R_{DS(on)}$ 较大、贵 |

**④ 临时救急（只有 NPN、电阻、5 V 电源）**

思路：**用 NPN 做"电平转换 + 电流放大"**，把 3.3 V 信号放大成能驱动栅极的电流。

```
   +5V ──[Rc 1kΩ]──┬──── [Rg 100Ω] ──── G
                   │                    │
   IO ──[Rb 1kΩ]── B                    │
                   │                 [Rpd 10kΩ]
                  NPN                   │
                   │                  GND
                  GND
```

**原理**：IO 高 → NPN 导通 → 集电极被拉到接近 GND → 通过 $R_g$ **把栅极拉低**（快速关断）；IO 低 → NPN 截止 → $R_c$ 把栅极**拉高到 5 V**（通过 $R_g$）。

**效果评估**：
- 栅极电压能到约 5 V（而非 3.3 V）→ 有所改善，但 **5 V 对 IRF540N 仍不充分**（需要 10 V）
- 这是**应急方案，不是解决方案**。根本办法还是**换逻辑电平 MOS 或加驱动 IC**

> **本题的教训**：**永远先看 $R_{DS(on)}$ 的测试条件，再决定驱动方案。**

**评分**：① 3 分；② 3 分；③ 2 分；④ 2 分。

### C2（10 分）

**① 可能原因（按可能性排序）**

| 排序 | 原因 | 说明 |
|---|---|---|
| 1 | **上下管直通（无死区 / 死区不足）** | 最常见。IR2104 有内置死区，但如果 PWM 信号接错、或用两个独立 IO 自己写互补 PWM 忘了死区，就会直通 |
| 2 | **自举电路问题** | 自举电容太小/没接、自举二极管装反或用了慢管，导致高边驱动电压不足 → 高边半开 → 发热炸 |
| 3 | **$V_{DS}$ 尖峰超限** | 电机是感性负载，走线电感大、没有吸收电路 → 关断尖峰超过管子耐压 |
| 4 | **栅极驱动问题** | $R_g$ 太小导致振铃、栅极走线太长、栅源下拉缺失导致误导通 |
| 5 | **IR2104 的 HS 脚（高边浮动地）接错** | 导致高边驱动基准错乱 |
| 6 | **母线电容不足 / 布局太差** | 换流尖峰没有就近吸收 |
| 7 | **管子本身耐压不够** | 24 V 母线用了 30 V 管子，尖峰直接超限 |
| 8 | **电源上电顺序 / 浪涌** | 电机启动电流冲击 |

**② 如何验证**

| 原因 | 验证方法 |
|---|---|
| 直通 | **示波器双通道同时看两个栅极波形**，测量死区时间是否 >0；或用差分探头看 $V_{DS}$ 是否同时为低 |
| 自举问题 | 量自举电容两端电压（应该是 $V_{CC}-0.7\text{ V}$ 左右）；量高边 $V_{GS}$ 波形，看平台电压是否够 |
| 尖峰 | 示波器看 $V_{DS}$ 峰值，和管子 $V_{DS}$ 额定值对比 |
| 栅极驱动 | 看栅极波形有无振铃、峰值有无超 ±20 V；量 $R_g$ 实际阻值 |
| 布局 | 量母线电容到管子的距离；观察功率回路面积 |
| 耐压 | 查 datasheet，确认 $V_{DS}$ 额定值和尖峰对比 |

**③ 检查直通的具体做法**
1. 示波器 **CH1 接上管 $V_{GS}$、CH2 接下管 $V_{GS}$**（注意用两个探头的地夹都接同一个 GND/HS 参考点，或分别正确参考）
2. 触发设置在**切换瞬间**（用单次触发）
3. **重点看：一个管子开始上升时，另一个是否已经完全下降**
4. 测量两者之间的"都不导通"时间 → 就是实际死区
5. **如果死区为 0 或出现重叠，就是直通**
6. 也可以看**母线电流**（串采样电阻），直通瞬间会有极大的电流尖峰

**④ 重新上电前的准备（至少 3 条）**

1. **用限流电源**：把电流限制设到很小（如 0.1 A），即使直通也不会立刻炸
2. **先不接电机**（空载测试），用示波器确认四个栅极波形和死区正常，再接负载
3. **降低母线电压**：先用 5~12 V 而不是 24 V 测试，确认时序正确后再升压
4. **检查所有接线**，特别是 IR2104 的 VB/VS/HO/LO 引脚和自举电容/二极管
5. **确认 PWM 信号源**：如果自己写互补 PWM，**先确认死区代码真的生效**（可以先用很低频率、占空比 5% 测试）
6. **加吸收电路**：RC 吸收、TVS 钳位
7. **准备备用管子**：炸管是学习的一部分，多备几个

**评分**：① 4 分（列出 4 种以上）；② 3 分；③ 1 分；④ 2 分。

## D 卷答案（评分要点）

| 项目 | 分值 | 要求 |
|---|---|---|
| 管子型号 + 手册 $R_{DS(on)}$ + 测试条件 | 2 分 | **测试条件必须写出来**（如 $V_{GS}=10\text{ V}, I_D=17\text{ A}$） |

- **表笔位置**：量 $V_{DS}$ 时表笔要尽量靠近管脚
- **万用表精度**：毫伏档本身的精度和零点

**D2 评分要点：**

| 项目 | 分值 | 要求 |
|---|---|---|
| 波形图 | 3 分 | 能看到明显的米勒平台（$V_{GS}$ 有一段平的） |
| 数据测量 | 3 分 | 平台电压、平台时间、$t_r$ 都有具体数值 |
| $R_g$ 对比 | 2 分 | 两个波形对比清晰，说明趋势 |
| 损耗计算 | 2 分 | 用**实测 $t_r$** 代入公式，不是用估算值 |

**预期趋势**：
- $R_g$ 从 10 Ω → 100 Ω，**$t_r$ 大约增大 5~10 倍**（近似与 $R_g$ 成正比）
- 平台持续时间明显变长
- 但 $R_g$ 小时**可能出现振铃**，振铃本身也会带来额外损耗和 EMI
