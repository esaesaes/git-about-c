## 1. 结构与原理 ★

### 1.1 名字的含义

**MOSFET** = **M**etal-**O**xide-**S**emiconductor **F**ield-**E**ffect **T**ransistor
= 金属-氧化物-半导体 **场效应**晶体管

名字里已经点明了两个关键：
- **Oxide（氧化物）**：栅极和沟道之间是**绝缘的二氧化硅**
- **Field Effect（场效应）**：靠**电场**控制，不靠电流控制

### 1.2 剖面结构（N 沟道增强型）

```
              G (栅极：多晶硅 / 金属)
              │
        ┌─────┴─────┐
        │   SiO₂    │  ← 绝缘层，厚度仅几十纳米
   ┌────┴───────────┴────┐
   │  N+       P 衬底   N+ │
   │ 源区     (Body)  漏区 │
   └──┬────────────────┬─┘
      │                │
      S ─────────────── D
      │      (衬底与源短接)
```

**三个决定一切的结构特征：**

| 特征 | 直接后果 |
|---|---|
| **栅极与沟道绝缘（SiO₂）** | **输入阻抗极高**（$10^9\ \Omega$ 以上），稳态栅极不吃电流 → 电压控制 |
| **栅氧层极薄（几十 nm）** | $V_{GS}$ 上限只有 **±20 V** 左右；**静电就能击穿，且不可逆** |
| **衬底与源极短接** | 形成一个寄生的 **PN 结（体二极管）**，见第 2 章 |

### 1.3 它是怎么导通的（物理过程）

以 N 沟道增强型为例，逐步理解：

1. $V_{GS}=0$：P 衬底中空穴是多数载流子，源漏之间是两个背靠背的 PN 结 → **不导通**
2. $V_{GS}$ 逐渐升高：栅极正电压通过氧化层产生**纵向电场**，把 P 衬底中的**电子吸引到表面**
3. $V_{GS}>V_{GS(th)}$：表面积累的电子足够多，形成一层**反型层（N 型沟道）**，把源区和漏区连通
4. 加上 $V_{DS}$：电子从源极经沟道流向漏极 → **导通**

**"增强型"的含义**：需要**额外加电压**才"增强"出沟道。默认关断 → 适合做开关。

**"耗尽型"的含义**：本身就有沟道，需要加负压把它"耗尽"掉。默认导通 → 少用。

### 1.4 端子的作用

| 端子 | 名称 | 作用 | 工程要点 |
|---|---|---|---|
| **G** | Gate 栅极 | 控制端 | 加电压控制沟道粗细 |
| **D** | Drain 漏极 | 电流流入（N 沟道） | 通常接负载 |
| **S** | Source 源极 | 电流流出（N 沟道） | **低边开关时接 GND** |
| **B** | Body 衬底 | 与 S 内部短接 | 一般不单独引出 |

> ▲ **为什么栅极叫"源极/漏极"**：这个名字来自**历史**。早期认为载流子从"源"出发、流向"漏"。对 N 沟道，电子确实从 S 流向 D。**但对 P 沟道，电流方向相反**——所以判符号时要靠箭头，不要靠名字猜。

### 1.5 符号与类型

**N 沟道增强型符号：**

```
        D
        │
   G ───┤  ┌──|<|──┐
        │  │       │   ← 体二极管：阳极在 S
        │  └───────┘
        │
        S
```

**符号三要素（记住就能判所有类型）：**

| 要素 | 含义 |
|---|---|
| **箭头方向** | N 沟道：箭头**指向沟道（向内）**；P 沟道：箭头**背离沟道（向外）** |
| **沟道线** | 实线 = 增强型（默认关断）；虚线/连续 = 耗尽型 |
| **体二极管** | N 沟道 **S→D**；P 沟道 **D→S** |

**四种类型：**

| 类型 | 导通条件 | 常见度 | 用途 |
|---|---|---|---|
| **N 沟道增强型** | $V_{GS}>V_{GS(th)}$ | ★最常用 | 低边开关、功率变换 |
| **P 沟道增强型** | $V_{GS}<V_{GS(th)}$（负） | 常用 | 高边开关、防反接 |
| N 沟道耗尽型 | $V_{GS}=0$ 导通 | 少见 | 恒流源、射频 |
| P 沟道耗尽型 | $V_{GS}=0$ 导通 | 很少 | — |

> **判断技巧**：看到符号先看箭头。**箭头指向里面（指向中间的竖线）的是 N 沟道。**

### 1.6 为什么 MOS 管怕静电 ★

栅氧层厚度只有**几十纳米**（1 nm = 10⁻⁹ m）。这个厚度能承受的电场约为 $10^7\ \text{V/cm}$ 量级，换算下来**栅源耐压只有约 ±20 V**。

**而人体静电可以达到几千伏**（冬天脱毛衣时能到 10 kV 以上）。

一旦静电电压超过栅氧击穿强度，氧化层被击穿 → **栅极和沟道短路 → 管子永久报废**。

**防护措施：**

| 措施 | 说明 |
|---|---|
| 手拿管子前先摸接地金属 | 泄放人体静电 |
| 使用防静电台垫、防静电手环 | 实验室标配 |
| 管子存放在防静电袋/管中 | **不要随手扔桌上** |
| 焊接时烙铁要接地 | 漏电烙铁是隐形杀手 |
| 电路板上栅源之间加保护 | 有的设计加齐纳二极管钳位（如 ±18 V） |

> ▲ **有个说法叫"MOS 管是拿在手里坏的，不是焊在板上坏的"**。虽然略夸张，但确实反映静电是最常见的失效原因之一。

## 2. 体二极管 ★

### 2.1 它是怎么形成的

衬底是 **P 型**（与源极 S 短接），漏区是 **N+**。P 和 N+ 接触就天然形成一个 **PN 结**。

**方向**：PN 结的阳极在 P 侧（= S），阴极在 N 侧（= D）。

```
   N 沟道 MOS 的体二极管：

        D (阴极)
        │
        ▲
       ╱ ╲      ← 二极管
      ╱   ╲
     ───────
        │
        S (阳极)
```

**记忆锁**：**N 沟道体二极管从 S 指向 D**（阳极 S，阴极 D）。

> **判断方法（不用背）**：衬底接 S，衬底是 P 型。PN 结阳极永远在 P 侧 → 阳极在 S。
> P 沟道同理：衬底是 N 型接 S → 阳极在 D，即 **D→S**。

### 2.2 它有什么用

| 场景 | 体二极管的作用 |
|---|---|
| **感性负载续流**（电机、继电器、电磁阀） | 关断时线圈电流通过体二极管回流 → **天然的续流路径** |
| **半桥/H 桥** | 死区期间和换流时的续流通道 |
| **同步整流 BUCK** | 死区期间由体二极管导通，避免输出断流 |
| **P-MOS 防反接** | 上电瞬间体二极管先导通，随后沟道导通降低压降 |
| **判断管子好坏** | 万用表量的就是这个二极管 |

### 2.3 它的三个"软肋" ★

| 软肋 | 说明 | 后果 |
|---|---|---|
| **压降大** | $V_F$ 约 **0.7~1.5 V**（随电流上升），远大于 MOS 导通的 $I\cdot R_{DS(on)}$（几十~几百 mV） | 续流期间发热明显 |
| **反向恢复慢** | 它是 PN 结，不是肖特基。$t_{rr}$ 可达**几十~几百 ns** | 半桥换流时产生**电流尖峰和额外损耗** |
| **不能长期当整流管** | 同上，高频下损耗不可接受 | 需要外并肖特基分担 |

**对比一下：**

| 器件 | 压降 | 反向恢复 |
|---|---|---|
| MOS 沟道导通 | $I\cdot R_{DS(on)}$（如 2 A × 50 mΩ = 0.1 V） | 无（多数载流子） |
| MOS 体二极管 | 0.7~1.5 V | 几十~几百 ns |
| 外并肖特基 | 0.3~0.5 V | 几乎无 |

> ▲ **所以"MOS 天然带续流二极管"这个说法只对了一半：**
> - **低频、小电流**（如几 kHz 的电机 PWM）：够用
> - **高频 PWM、半桥、同步整流**：体二极管的反向恢复会成为**主要损耗和尖峰来源**，必须评估，甚至外并肖特基

### 2.4 一个重要的工程推论

**半桥电路里，死区时间是体二极管导通的时间。**

死区越长 → 体二极管导通越久 → 损耗越大（因为压降比沟道大得多）
死区越短 → 直通风险越高

**这就是"死区时间要优化而不是越大越好"的原因。**

## 3. 五个工作区 ★★（重点）

### 3.1 为什么是"五个"

很多教材只说三个（截止、可变电阻、饱和）。但工程上更实用的是**按 $V_{GS}$ 分五段**：

| # | 区域 | 条件 | $I_D$ | 类比 |
|---|---|---|---|---|
| 1 | **截止区** | $V_{GS}<V_{GS(th)}$ | $\approx0$ | 断开的开关 |
| 2 | **亚阈值区** | $V_{GS}$ 略低于 $V_{GS(th)}$ | 微小但**指数增长** | "半开半关"，危险 |
| 3 | **可变电阻区**（线性/欧姆区） | $V_{GS}>V_{GS(th)}$ 且 $V_{DS}<V_{ov}$ | 由 $V_{DS}$ 决定 | **完全导通的开关** |
| 4 | **饱和区**（恒流区/放大区） | $V_{GS}>V_{GS(th)}$ 且 $V_{DS}>V_{ov}$ | 由 $V_{GS}$ 决定 | 恒流源 |
| 5 | **击穿区** | $V_{DS}>V_{(BR)DSS}$ | 雪崩 | 损坏 |

其中 $V_{ov}=V_{GS}-V_{GS(th)}$ 叫**过驱动电压**。

**输出特性曲线（看清三个区）：**

```
   Id
    │          饱和区（恒流区）
    │          ← 曲线几乎水平 →
    │    ┌────────────────────── Vgs 很大
    │   ╱├────────────────────── Vgs 大
    │  ╱ ├────────────────────── Vgs 中
    │ ╱  ├────────────────────── Vgs = Vth (临界)
    │╱   │
  ──┼────┼─────────────────────── Vds
    0    Vov
     ↑
  可变电阻区
  (Vds < Vov)
```

### 3.2 亚阈值区为什么重要 ★

在 $V_{GS}$ 略低于 $V_{GS(th)}$ 时，**沟道没有完全形成，但已经有微小电流**，且这个电流随 $V_{GS}$ **指数增长**。

**亚阈值区的两个工程意义：**

1. **对"关断"是坏事**：温度升高 → 亚阈值电流指数增大 → 高温下漏电大 → 静态功耗上升
2. **对"导通"极其危险**：如果驱动电压刚好落在亚阈值区边缘，管子的 $R_{DS(on)}$ 会大得离谱

> ▲ **这正是"3.3 V 驱动标准 MOS 会烧管"的物理本质**：$V_{GS(th)}=2.0\sim4.0\text{ V}$ 的管子，在 3.3 V 时可能刚好在亚阈值区或临界区 → $R_{DS(on)}$ 是标称值的几十倍 → 功耗爆炸。

**量化一下**：
- 手册 $R_{DS(on)}=44\text{ m}\Omega$（在 $V_{GS}=10\text{ V}$ 下）
- 3.3 V 驱动时实测 $R_{DS(on)}$ 可能达到 **0.5~1 Ω**（十几倍）
- 2 A 电流下：$P=I^2R$
  - 充分导通：$2^2\times0.044=0.18\text{ W}$
  - 驱动不足：$2^2\times0.6=2.4\text{ W}$ —— **差 13 倍！**

### 3.3 ★★★ 术语陷阱：两种"饱和"含义相反

**这是学 MOS 最容易出错、也最影响沟通的一点。**

| 术语 | BJT（三极管）中的"饱和" | MOSFET 中的"饱和" |
|---|---|---|
| 物理状态 | 两个 PN 结都正偏 | 沟道在漏端夹断 |
| 电压 | $V_{CE}$ **很小**（0.1~0.3 V） | $V_{DS}$ **较大** |
| 电流 | 由外电路决定 | 由 $V_{GS}$ 决定 |
| 像什么 | **闭合的开关**（导通最好） | **恒流源**（导通很差） |
| 做开关时 | **应该用这个区** ✅ | **绝对不能在这个区** ❌ |

**用数字说明为什么 MOS 不能在饱和区当开关：**

假设负载是 4 Ω，电源 12 V，MOS 工作在饱和区（比如 $V_{DS}=3\text{ V}$）：
- 则负载上的电压只有 $12-3=9\text{ V}$
- 电流 $I_D=9/4=2.25\text{ A}$
- MOS 功耗 $P=3\times2.25=6.75\text{ W}$（**巨大的浪费 + 巨热**）

对比在可变电阻区（$R_{DS(on)}=0.05\ \Omega$）：
- $V_{DS}\approx I\times R=0.11\text{ V}$
- 功耗 $P=0.11\times2.25=0.25\text{ W}$（**小 27 倍**）

> ▲ **为了避免歧义，工程上建议这样表述：**
> - 说 **"完全导通 / 充分导通 / 深度导通"** → 指可变电阻区
> - 说 **"工作在恒流区 / 放大区 / 有源区"** → 指饱和区
> - **避免单独说"MOS 的饱和区"**，因为对方不知道你指哪个意思

### 3.4 怎么保证工作在可变电阻区

**条件**：
$$V_{GS}-V_{GS(th)}>V_{DS}$$

**工程上怎么做：**

1. **让 $V_{GS}$ 足够大**：经验法则是 $V_{GS}$ 取 $V_{GS(th)}$ 的 **3~4 倍**
2. **查手册的 $R_{DS(on)}$ 测试条件**，确保实际 $V_{GS}$ ≥ 该条件
3. **注意 $V_{DS}$ 不能太大**：$V_{DS}=I_D\cdot R_{DS(on)}$，本来就很小

**判断"是否充分导通"的实用标准：**

| 判断 | 结论 |
|---|---|
| $V_{DS}$ 只有几十~几百 mV | ✅ 充分导通 |
| $V_{DS}$ 有几伏 | ❌ 驱动不足或在恒流区 |
| $V_{DS}\approx V_{CC}$ | ❌ 根本没导通 |

> **这个判断方法很有用**：维修时万用表量一下 $V_{DS}$，就知道 MOS 是不是在正常工作。

## 4. 数据手册怎么读 ★★（无器材时的"实践"）

> **这一章是可以真正动手的。** 去 TI / Infineon / onsemi / 立创商城下载一份 MOSFET 的 datasheet（如 IRF540N），对着看。

### 4.1 快速定位：6 个决定性参数

**不要从头读到尾。** 直接找这几项：

| # | 参数 | 在哪一节 | 决定什么 |
|---|---|---|---|
| 1 | $V_{(BR)DSS}$ / $V_{DSS}$ | Absolute Maximum Ratings | 耐压够不够 |
| 2 | $R_{DS(on)}$ | Electrical Characteristics | **发热多少（最关键）** |
| 3 | $V_{GS(th)}$ | Electrical Characteristics | 驱动电压要求 |
| 4 | $Q_g$ | Electrical Characteristics | 驱动电流需求 |
| 5 | $R_{th(j-c)}$ / $R_{th(j-a)}$ | Thermal Characteristics | 能不能散热出去 |
| 6 | $E_{AS}$ | Absolute Maximum Ratings | 感性负载的耐受能力 |

### 4.2 $R_{DS(on)}$ 那一行藏着最大的坑 ★

datasheet 里 $R_{DS(on)}$ 通常**不止一行**，长这样：

| Symbol | Parameter | Test Conditions | Min | Typ | Max | Unit |
|---|---|---|---|---|---|---|
| $R_{DS(on)}$ | Drain-to-Source On-Resistance | $V_{GS}=10\text{ V},\ I_D=17\text{ A}$ | — | 44 | 52 | mΩ |
| | | $V_{GS}=4.5\text{ V},\ I_D=15\text{ A}$ | — | 60 | 77 | mΩ |

**关键认识：**

1. **每一行都有 Test Conditions（测试条件）**——**脱离条件谈 $R_{DS(on)}$ 没有意义**
2. **Typ 和 Max 要分开看**：设计时应该用 **Max**（最坏情况），不是 Typ（典型值）
3. **看有没有你需要的 $V_{GS}$ 那一行**：
   - 只有 $V_{GS}=10\text{ V}$ 一行 → 这是**标准 MOS**，3.3 V/5 V 驱动不行
   - 有 $V_{GS}=4.5\text{ V}$ 甚至 $2.5\text{ V}$ 的行 → **逻辑电平 MOS**，可以用低压驱动

> ▲ **选型第一铁律：先看你需要的 $V_{GS}$ 下有没有 $R_{DS(on)}$ 数据。**
> 如果手册只给了 10 V 下的值，而你要用 3.3 V 驱动 → **换型号**。

### 4.3 $R_{DS(on)}$ 不是常数：必须看曲线

datasheet 后面有 **Typical Characteristics** 曲线区，其中两张最关键：

**曲线 1：$R_{DS(on)}$ vs $T_j$（正温度系数）**

```
  Rds(on)
   │                    ╱
 2×├──────────────────╱
   │                ╱
 1×├──────────────╱
   │           ╱
   └──┬────┬───┬────┬───→ Tj
     25   50  75  100  125  (°C)
```

**典型规律**：$R_{DS(on)}$ 随结温**上升**，大致：

$$R_{DS(on)}(T_j)\approx R_{DS(on),25°C}\times[1+k(T_j-25)]$$

$k$ 约为 **0.4%~0.8% / °C**（不同管子不同，也能从曲线上读）。

**工程上的实操做法（记这个表）：**

| 目标结温 $T_j$ | 相对 25°C 的倍率（估） |
|---|---|
| 25 °C | 1.0× |
| 50 °C | 1.15~1.2× |
| 75 °C | 1.3~1.4× |
| 100 °C | **1.5~1.7×** |
| 125 °C | 1.7~2.0× |

> ▲ **热设计必须用"热态电阻"**。用 25°C 的值算，会严重低估发热，这是新手最常犯的错误。

这张图告诉你"驱动电压降到多少，电阻开始暴增"，是判断"能不能用 3.3 V 驱动"的直接依据。

**曲线 3：$I_D$ vs $V_{GS}$（转移特性）**

### 4.4 Absolute Maximum Ratings 的正确理解 ★

这一节的所有值都是**绝对不能超过的极限**，而且**通常是 $T_c=25°C$ 条件下的理想值**。

| 参数 | 陷阱 |
|---|---|
| $I_D$ 连续漏极电流 | **标的是 $T_c=25°C$**。实际能过的电流由**热**决定，可能只有标称值的 1/10 |
| $I_{DM}$ 脉冲电流 | 有脉宽限制 |
| $P_D$ 总功耗 | **也是 $T_c=25°C$**，不装散热片根本达不到 |
| $V_{GS}$ | ±20 V 左右，**超过就击穿栅氧** |
| $E_{AS}$ | 雪崩能量，感性负载关断时的重要指标 |

**为什么 $I_D$ 最不可信？**

$$I_{max}\approx\sqrt{\frac{T_{j,max}-T_a}{R_{DS(on),hot}\cdot R_{th(j-a)}}}$$

**举例**：$T_{j,max}=150°C$，$T_a=25°C$，$R_{DS(on),hot}=0.1\ \Omega$，$R_{th(j-a)}=62\ °C/W$

$$I_{max}=\sqrt{\frac{150-25}{0.1\times62}}=\sqrt{20.2}\approx4.5\text{ A}$$

**而手册可能标 $I_D=30\text{ A}$！** 差了近 7 倍。

> ▲ **所以：选型时永远用热公式算，不要相信 $I_D$ 那个数字。**

### 4.5 读手册的完整检查清单

拿到一个 MOS 管的 datasheet，按这个顺序判断能不能用：

- [ ] **$V_{DSS}$** ≥ 工作电压 × 2~3（感性负载取 3 倍）
- [ ] **$R_{DS(on)}$** 在我的驱动电压下有没有数据？Max 值是多少？
- [ ] **$V_{GS(th)}$** 范围是否保证我能可靠开通和关断？
- [ ] **$Q_g$** 是否匹配我的驱动能力（$I=Q_g/t$）？
- [ ] **$R_{th}$** 能否把热量导出（算 $T_j$）？
- [ ] **$V_{GS(max)}$** 我的驱动电路不会超过它？
- [ ] **封装**是否适合我的散热方式和板子空间？
- [ ] 感性负载的话，**$E_{AS}$** 够不够？

## 5. 栅极驱动 ★★★（本章是核心）

> **MOS 管学习的真正门槛在这里。** 前面都是"知道"，这一章是"会不会用"。

### 5.1 一个看似矛盾的事实

- MOS 管是**电压控制**器件，**稳态下栅极电流几乎为 0**
- **但开关瞬间，栅极需要一个很大的脉冲电流**（几百 mA 到几 A）

**为什么？** 因为栅极本质上是一个**电容**。

$$Q=C\cdot U\quad\Longrightarrow\quad Q_g=C_{iss}\cdot V_{drive}$$

**每次开关都要搬运电荷 $Q_g$：**

$$I_{drive}=\frac{Q_g}{t_{switch}}$$

**举例**：$Q_g=30\text{ nC}$，希望开关时间 100 ns
$$I_{drive}=\frac{30\times10^{-9}}{100\times10^{-9}}=0.3\text{ A}=300\text{ mA}$$

**而单片机 IO 通常只有 20 mA** —— **差了 15 倍**。

> **这就是"IO 直驱 MOS 开关很慢"的定量解释。**

### 5.2 $Q_g$ 的数量感（帮你选型时判断）

| 管子类型 | $Q_g$ 量级 | 说明 |
|---|---|---|
| 小信号 MOS（SOT-23） | 1~10 nC | 可以用 IO 驱 |
| 中功率（TO-220 逻辑电平） | 10~40 nC | 需要一定驱动能力 |
| 大功率（低 $R_{DS(on)}$） | 50~200 nC | 需要专用驱动 IC |
| 超大功率模块 | 数百 nC ~ µC | 需要强驱动 |

**规律**：**$R_{DS(on)}$ 越小（芯片越大），$Q_g$ 越大** —— 这是一对矛盾。
**没有"又低阻又好驱"的管子**，必须权衡。

### 5.3 米勒平台（Miller Plateau）★★

**这是本章最重要的知识点。**

给栅极充电时，$V_{GS}$ 的上升**不是一条直线**，中间有一段"平台"：

```
  Vgs
   │
Vdr├─────────────────┐
   │                 │
   │            ┌────┘  ← 米勒平台
   │           ╱
   │         ╱
Vth├───────╱
   │     ╱
  0└────┴─────┴───────┴──→ t
      t1   平台      t2
     (Qgs)  (Qgd)
```

**三个阶段：**

| 阶段 | 消耗的电荷 | 发生了什么 | 损耗 |
|---|---|---|---|
| **① 开通延迟 + 电流上升** | $Q_{gs}$ | $V_{GS}$ 升到 $V_{GS(th)}$，$I_D$ 开始上升 | 小 |
| **② 米勒平台** | **$Q_{gd}$** | **$V_{GS}$ 几乎不变，$V_{DS}$ 快速下降** | **★★★ 最大** |
| **③ 完全导通** | 剩余电荷 | $V_{GS}$ 升到驱动电压，$R_{DS(on)}$ 降到最低 | 小 |

**为什么会有平台（物理原因）：**

在第二阶段，$V_{DS}$ 正在**快速变化**（从 $V_{CC}$ 降到接近 0）。这个变化通过**米勒电容 $C_{gd}$** 耦合到栅极，把刚充进去的电荷"吸走"了。

于是驱动电流**全部被用来对付这个耦合**，$V_{GS}$ 就停在原地不动 —— 这就是**米勒效应**。

**为什么这一阶段损耗最大：**

在平台期间：
- **电流 $I_D$ 已经建立起来了**（大）
- **电压 $V_{DS}$ 还很高**（大）
- **$P=V\times I$ 两者同时很大** → 瞬时功率极高

这是整个开关过程中唯一"电压和电流同时很大"的时段。

**工程结论：**

| 结论 | 说明 |
|---|---|
| **平台越长，开关损耗越大** | 平台长度由 $Q_{gd}$ 和驱动电流决定 |
| **选管子时看 $Q_{gd}$，不只看 $C_{iss}$** | $Q_{gd}$ 才是开关损耗的直接决定因素 |
| **要缩短平台只有一条路：加大驱动电流** | 降低 $R_g$、用驱动 IC、用推挽 |
| **这是"栅极驱动为什么重要"的最终答案** | |

### 5.4 开关损耗的定量关系

$$P_{sw}\approx\frac{1}{2}V_{DS}\cdot I_D\cdot(t_r+t_f)\cdot f_{sw}$$

**三个关键比例关系：**

| 关系 | 含义 |
|---|---|
| $P_{sw}\propto f_{sw}$ | **频率越高，开关损耗越大（成正比）** |
| $P_{sw}\propto (t_r+t_f)$ | 开关越慢，损耗越大 |
| $P_{cond}=I_D^2 R_{DS(on)}$ **与频率无关** | 导通损耗是"底噪" |

**这解释了电源设计的核心权衡：**

```
损耗
 │        ╱ 开关损耗（∝ f）
 │      ╱
 │    ╱
 │  ─────────── 导通损耗（与 f 无关）
 │ ╱
 └──────────────→ 开关频率
      ↑
   存在最优频率
```

- **频率太低**：电感/电容体积大、纹波大、动态响应差
- **频率太高**：开关损耗爆炸、驱动困难、EMI 严重
- **中间有个最优点**

**栅极驱动本身的损耗**（通常较小但要知道）：
$$P_{gate}=Q_g\cdot V_{GS}\cdot f_{sw}$$

### 5.5 栅极电阻 $R_g$ ★

**作用**：限制栅极充放电的**峰值电流**，从而控制开关速度。

$$I_{peak}\approx\frac{V_{drive}}{R_g+R_{driver,内部}}$$

**取值权衡（这是设计的艺术）：**

| $R_g$ 太小 | $R_g$ 太大 |
|---|---|
| 开关快 → 开关损耗小 ✅ | 开关慢 → 开关损耗大 ❌ |
| **dV/dt 大 → 振铃、EMI、可能被干扰误开通** ❌ | 波形干净、EMI 好 ✅ |
| 栅极峰值电流可能超过驱动能力 ❌ | 米勒平台变长 ❌ |
| 可能与走线电感谐振 ❌ | 死区时间要相应加长 |

**经验值**：

| 场合 | $R_g$ |
|---|---|
| 小信号 MOS，低频 | 100 Ω ~ 1 kΩ |
| 一般功率开关 | **10~47 Ω** |
| 追求快速开关 | 1~10 Ω（需要强驱动） |
| 有专门驱动 IC | 2~22 Ω |

**进阶技巧：**

| 技巧 | 做法 | 目的 |
|---|---|---|
| **非对称驱动** | 开通和关断用不同电阻 | 关断更快可减少死区损耗 |
| **二极管加速** | 电阻并联一个二极管 | 单向加速 |
| **有源米勒钳位** | 专用电路在关断时钳住栅极 | 防止 dV/dt 引起的误开通 |

### 5.6 栅源下拉电阻 $R_{pd}$（必装）★

**这是最容易被忽略、后果最严重的元件。**

**作用**：
1. 给栅极提供**确定电位**（默认关断）
2. **泄放 $C_{iss}$ 上积累的电荷**

**不装的危险场景：**

| 场景 | 后果 |
|---|---|
| **上电瞬间** | 单片机复位期间 IO 是高阻态，栅极悬空 → 栅极电荷无处泄放 → **MOS 误导通 → 电机在程序还没跑起来时就全速转** |
| **程序卡死/IO 置高阻** | 同上 |
| **干扰耦合** | 栅极积累电荷 → 误导通 |
| **静电** | 悬空栅极更容易被击穿 |

**取值**：**10 kΩ** 是标准值。太小会增加驱动负担，太大起不到作用。

> ▲ **"上电就转"是新手最常见的诡异故障，99% 是因为没装这个电阻。**

### 5.7 三种驱动方案的对比 ★

| 方案 | 峰值电流 | 速度 | 复杂度 | 适用 |
|---|---|---|---|---|
| **单片机 IO 直驱** | ≤20 mA | 慢（µs 级） | 最简单 | 逻辑电平 MOS、低频、小电流 |
| **三极管推挽** | 几百 mA | 中 | 中等 | 中等功率，成本敏感 |
| **专用驱动 IC** | 1~4 A | 快（几十 ns） | 简单（外接即可） | 大功率、高频、半桥（推荐） |

#### （1）IO 直驱的前提条件

**必须同时满足：**
- [ ] MOS 是**逻辑电平**类型（手册有 $V_{GS}=4.5\text{ V}$ 或更低的 $R_{DS(on)}$ 数据）
- [ ] $Q_g$ 小（< 10 nC 更好）
- [ ] 必须加**栅极串阻**（保护 IO）
- [ ] 必须加**栅源下拉**
- [ ] 开关频率低（< 1 kHz 比较安全）
- [ ] 感性负载要加续流二极管

**"栅极串阻为什么必须加"**：如果直接接 IO，栅极电容瞬间短路 → 峰值电流可能达到安培级 → **烧 IO**。

#### （2）三极管推挽驱动

**原理**：用一对 NPN + PNP 组成"图腾柱"。

```
        VCC
         │
        ┌┴┐ PNP
   ┌────┤ ├────┐
   │    └┬┘    │
IO─┤     │     ├──[Rg]── G
   │    ┌┴┐    │
   └────┤ ├────┘
        └┬┘ NPN
         │
        GND
```

**工作过程**：
- IO 输出**高** → NPN 导通 → **快速把栅极拉低**（关断）
- IO 输出**低** → PNP 导通 → **快速把栅极拉高到 VCC**（开通）

**优点**：能提供几百 mA 峰值电流；还能顺便做**电平转换**（3.3 V 信号 → 12 V 驱动）
**缺点**：有交越失真（两个管子换向瞬间的短暂"都不导通"）；速度不如专用 IC

#### （3）专用栅极驱动 IC（推荐）

| 类型 | 典型芯片 | 说明 |
|---|---|---|
| **低边驱动** | TC4427、UCC27517、MCP1407 | 单管驱动，简单 |
| **半桥驱动** | IR2104、IR2110、EG2133 | 带自举，可驱动上下管 |
| **隔离驱动** | 光耦驱动（TLP250）、变压器驱动 | 高压隔离场合 |

**优点**：
- 峰值电流大（1~4 A）→ 开关快
- **自带死区**（半桥必须）
- **自带自举**（高边 N 沟道必须）
- 常带保护（欠压闭锁 UVLO、过流保护）

### 5.8 自举电路（高边 N 沟道驱动）★★

**这是高边 N 沟道最关键的配套电路。**

#### 问题是什么

N 沟道做高边开关时，**源极 S 接负载、电位接近 $V_{CC}$**。

要让 $V_{GS}>10\text{ V}$，栅极电压必须**比 $V_{CC}$ 还高 10 V 以上**。

**例**：$V_{CC}=12\text{ V}$，需要 $V_{GS}=10\text{ V}$ → 栅极要到 **22 V**。

但系统里只有 12 V 电源 —— **产生不了 22 V**。

#### 解决方案：自举电容"垫高"电压

```
        VCC ──────────────┬──────── D
                          │
                    ┌─────┴─────┐
                    │  高边 MOS  │
       ┌────────────┤           │
       │            └─────┬─────┘
   ┌───┴───┐              │
   │ 自举  │              ├──── 输出（接到电机等负载）
   │ 二极管│              │
   └───┬───┘        ┌─────┴─────┐
       │            │  低边 MOS  │
   ┌───┴───┐        └─────┬─────┘
   │ 自举  │              │
   │ 电容  │             GND
   └───┬───┘
       └──── 驱动 IC 的 VB（高边浮动电源脚）
```

**四步工作原理：**

1. **低边导通时**：输出被拉到 GND
2. **自举电容充电**：通过自举二极管从 $V_{CC}$ 充电到约 $V_{CC}-0.7\text{ V}$（二极管压降）
3. **切换**：低边关断，高边要开通
4. **电压叠加**：电容的负极"坐"在源极电位上（接近 $V_{CC}$），正极就被抬到 $V_{CC}+(V_{CC}-0.7)$ → **约 22 V**，足以驱动高边

**设计要点：**

| 元件 | 选择 | 理由 |
|---|---|---|
| 自举电容 | **0.1~1 µF**（陶瓷，低 ESR） | 要足够大，能提供 $Q_g$ 还有余量 |
| 自举二极管 | **快恢复或肖特基** | 普通二极管反向恢复慢，会失效 |
| 布局 | 紧靠驱动 IC 的 VB-VS 脚 | 减小回路电感 |

**自举电路的两个限制（重要）：**

| 限制 | 说明 | 对策 |
|---|---|---|
| **占空比不能是 100%** | 高边一直导通时，低边不导通 → 自举电容无法充电 → 电压逐渐下降 → 高边驱动失效 | 定期"刷新"（周期性关断高边）；或用**电荷泵** |
| **启动需要"预充电"** | 刚上电时电容没充电，第一个周期高边可能驱动不足 | 驱动 IC 内部有启动逻辑；或用**脉冲充电** |

> ▲ **"占空比 100% 时高边没驱动"是半桥电路的一个经典坑**，很多人在做直流电机全速时会遇到。

## 6. 损耗与热设计 ★★

### 6.1 热路 = 电路（最快的理解方式）

**把热当电来算，一切就清楚了：**

| 电学量 | 热学量 | 单位 |
|---|---|---|
| 电压 $U$ | **温差** $\Delta T$ | °C |
| 电流 $I$ | **功耗** $P$ | W |
| 电阻 $R$ | **热阻** $R_{th}$ | °C/W |
| 电容 | 热容（决定升温快慢） | J/°C |

$$\boxed{\Delta T=P\times R_{th}}$$

**这正是欧姆定律 $U=IR$ 的形式。**

### 6.2 热阻链条（串联）

热量从**芯片内部**传到**环境空气**，要经过几段：

```
   Tj（结温）
    │  Rth(j-c)  结到壳
   Tc（壳温）
    │  Rth(c-s)  壳到散热片（硅脂/绝缘垫）
   Ts（散热片）
    │  Rth(s-a)  散热片到环境
   Ta（环境温度）
```

$$R_{th(j-a)}=R_{th(j-c)}+R_{th(c-s)}+R_{th(s-a)}$$

**各段典型值：**

| 热阻 | 典型值 | 说明 |
|---|---|---|
| $R_{th(j-c)}$ | 1~5 °C/W | 管子本身的封装能力，查手册 |
| $R_{th(c-s)}$ | 0.5~2 °C/W | 硅脂约 0.5；绝缘垫可能 1.5~2 |
| $R_{th(s-a)}$ | 5~50 °C/W | 散热片规格，越大越小 |
| **$R_{th(j-a)}$（无散热片）** | **50~65 °C/W**（TO-220） | 这是**最常用的默认值** |

**不同封装的大致对比：**

| 封装 | 无散热片 $R_{th(j-a)}$ |
|---|---|
| SOT-23 | 200~350 °C/W（很差） |
| SOT-223 / DPAK | 60~100 °C/W |
| TO-220 | **50~65 °C/W** |
| TO-247 | 35~45 °C/W |
| D2PAK（大铺铜） | 30~50 °C/W |

> ▲ **注意这个数字的后果**：TO-220 无散热片 62 °C/W，意味着**每 1 W 功耗升温 62°C**。
> **所以"无散热片时 1 W 就是上限"** —— 这是个非常好用的工程直觉。

### 6.3 热设计完整五步法 ★★

**背下来，以后选管子直接用：**

| 步骤 | 做什么 | 注意 |
|---|---|---|
| **① 确定工作电流** | 用**最大持续电流**或**峰值电流**，不是平均值 | 电机堵转电流可能是额定的 5~10 倍 |
| **② 取热态 $R_{DS(on)}$** | 按目标 $T_j$ 从曲线读，或估为 25°C 值的 **1.5~1.7 倍** | **绝不能用 25°C 的值** |
| **③ 算功耗** | $P=I^2\cdot R_{DS(on),hot}$ | 若有 PWM 还要加开关损耗 |
| **④ 算允许热阻** | $R_{th(允许)}=\dfrac{T_{j,max}-T_a}{P}$ | |
| **⑤ 对比** | 实际 $R_{th(j-a)}$ 必须 **< 允许值** | 否则加散热片或换管子 |

### 6.4 完整算例（含正反馈陷阱）★★

**条件：**
- $V_{CC}=12\text{ V}$，负载 $R_L=3\ \Omega$
- $R_{DS(on),25°C}=40\text{ m}\Omega$
- $R_{th(j-a)}=62\text{ °C/W}$，$T_a=40\text{ °C}$，$T_{j,max}=150\text{ °C}$
- 热态倍率取 **1.7**

**① 工作电流**
$$I_D\approx\frac{V_{CC}}{R_L}=\frac{12}{3}=4\text{ A}$$

**② 热态电阻**
$$R_{DS(on),hot}=0.04\times1.7=0.068\ \Omega$$

**③ 功耗**
$$P=I_D^2\cdot R=4^2\times0.068=16\times0.068=1.088\text{ W}$$

**④ 结温**
$$T_j=T_a+P\cdot R_{th(j-a)}=40+1.088\times62=40+67.5=107.5\text{ °C}$$

**⑤ 判断**
- $107.5\text{ °C}<150\text{ °C}$ → **安全**，但余量只有约 42°C
- 环境升到 **60 °C**：$T_j=60+67.5=127.5\text{ °C}$ → 余量只剩 22°C，**已经很紧张**

### 6.5 ★ 正反馈陷阱（热失控）

**上面第 ⑤ 步其实不严谨。** 因为：

```
   结温升高
      ↓
   Rds(on) 变大（正温度系数）
      ↓
   功耗变大
      ↓
   结温进一步升高  ← 回到起点！
```

**这是一个正反馈循环。**

**所以正确的做法是迭代（或解方程）：**

设 $T_j$ 为未知量，$R_{DS(on)}(T_j)=R_{25}[1+k(T_j-25)]$：

$$T_j=T_a+I^2\cdot R_{25}[1+k(T_j-25)]\cdot R_{th}$$

**代入上面的数字**（$R_{25}=0.04\ \Omega$，$I^2R_{25}R_{th}=16\times0.04\times62=39.68$）：

为了让"100°C 时倍率约 1.7"这个假设自洽，取 $k=0.0093/°C$（即约 0.93%/°C）：

$$T_j=40+39.68\times[1+0.0093(T_j-25)]$$

$$T_j=40+39.68\times[1+0.0093T_j-0.2325]$$

$$T_j=40+39.68\times[0.7675+0.0093T_j]$$

$$T_j=40+30.45+0.369T_j$$

$$T_j-0.369T_j=70.45\quad\Rightarrow\quad 0.631T_j=70.45\quad\Rightarrow\quad T_j\approx111.7\text{ °C}$$

**迭代法（更直观）：**

| 迭代 | 假设 $T_j$ | 倍率 | $R_{hot}$ | $P$ | 算出新 $T_j$ |
|---|---|---|---|---|---|
| 1 | 100 °C | 1.70 | 0.068 | 1.086 W | 107.4 |
| 2 | 107.4 °C | 1.77 | 0.071 | 1.13 W | 110.1 |
| 3 | 110.1 °C | 1.79 | 0.072 | 1.146 W | 111.1 |
| 4 | 111.1 °C | 1.80 | 0.072 | 1.152 W | 111.4 |
| 5 | 111.4 °C | 1.80 | 0.072 | 1.155 W | 111.6 |
| **收敛** | **~111.7 °C** | 1.81 | 0.072 | 1.156 W | — |

**结论：真实结温约 111.7 °C，比初步估算的 107.5 °C 高了约 4 °C，但仍在安全范围。**

> ▲ **注意正反馈的两面性：**
> - **坏消息**：它让结温比估算值更高，热设计必须留余量
> - **好消息**：因为 $R_{DS(on)}$ 是**正**温度系数，**MOS 管可以并联**（温度高的那个电阻大、电流小，自动均流）
>
> **对比三极管**：$V_{BE}$ 是**负**温度系数，并联会热失控 → **三极管不能简单并联，MOS 可以。**

### 6.6 什么时候会热失控（危险信号）

**单纯的 $R_{DS(on)}$ 正反馈不会无限发散**（因为它是线性的，方程有解）。

**但以下情况真的会失控：**

| 情况 | 机理 |
|---|---|
| **工作在恒流区/线性区**（不是开关） | $P=V_{DS}\cdot I_D$，电压电流都大，且没有 $R_{DS(on)}$ 的"自限"作用 |
| **驱动不足** | $V_{GS}$ 落在亚阈值区边缘，$I_D$ 对温度极其敏感 |
| **并联时严重不均流** | 一个管子承担全部电流 |
| **散热完全失效** | 散热片脱落、风扇停转 |

> ▲ **线性应用（线性电源、电子负载、音频功放）是 MOS 最容易热失控的场合**，必须做**降额 + 温度保护（NTC + 关断）**。开关应用相对安全。

### 6.7 散热手段（按效果排序）

| 手段 | 说明 | 效果 |
|---|---|---|
| **降额使用** | 选大一号的管子、降低电流 | 最有效也最省事 |
| **散热片** | TO-220/TO-247 加铝散热片 | $R_{th(s-a)}$ 从 60 降到 5~20 |
| **硅脂** | 填充微观空隙 | 降低 $R_{th(c-s)}$ 约 0.5~1 |
| **铺铜 + 过孔阵列** | 贴片 MOS 的主要散热路径 | 过孔越多越好 |
| **增大封装** | D2PAK 比 SOT-23 好得多 | |
| **风冷** | 加风扇 | 显著改善 |
| **绝缘垫** | 需要电气隔离时 | **但会增加热阻**，权衡 |

## 7. 典型电路 ★

### 7.1 低边开关（最常用）

```
        VCC
         │
       [负载]   ← 电机 / LED灯带 / 加热丝
         │
         D
         │
   G ────┤  N-MOS
         │
         S
         │
        GND

  IO ──[Rg 10~100Ω]── G
                      │
                   [Rpd 10kΩ]  ← 必须
                      │
                     GND
```

| 元件 | 作用 | 典型值 | 不装的后果 |
|---|---|---|---|
| $R_g$ | 限栅极峰值电流、抑制振铃 | 10~100 Ω | 可能烧 IO、振铃 |
| $R_{pd}$ | 防悬空误导通 | 10 kΩ | **上电就导通** |
| 续流二极管 | 感性负载保护 | 肖特基 | **关断瞬间被反电动势击穿** |

**优点**：驱动简单（源极接地，栅极用普通电压即可）
**缺点**：负载不接地（不能与其他电路共地）

### 7.2 高边开关

#### 方案 A：P 沟道（简单）

```
        VCC
         │
         S
         │
   G ────┤  P-MOS
         │
         D
         │
       [负载]
         │
        GND
```

- **栅极拉低（到 GND）时导通**
- 驱动：用 NPN 三极管或小 NMOS 把栅极拉到 GND
- **注意 $V_{GS}$ 不能超过 ±20 V**：$V_{CC}$ 高时要加分压或齐纳钳位

**优点**：驱动简单，不需要自举
**缺点**：P 沟道 $R_{DS(on)}$ 比同规格 N 沟道**大 2~3 倍**，价格也更高

#### 方案 B：N 沟道 + 自举（性能好）

见 5.8。**大电流/高电压场合首选。**

#### 选择逻辑

| 条件 | 推荐 |
|---|---|
| $V_{CC}<20\text{ V}$，电流不大（<2 A） | **P 沟道**，简单省事 |
| 高压、大电流 | **N 沟道 + 驱动 IC + 自举** |

### 7.3 半桥 / H 桥 ★

```
        VCC
     ┌───┴───┐
     │ 上管  │  ← 高边 N-MOS（需要自举驱动）
     └───┬───┘
         ├────── 输出（接电机一端）
     ┌───┴───┐
     │ 下管  │  ← 低边 N-MOS
     └───┬───┘
        GND
```

**H 桥 = 两个半桥并联**，可以实现电机**正反转**和**刹车**。

**必备要素清单：**

- [ ] **自举电路**（驱动高边）
- [ ] **死区时间**（防止直通）
- [ ] **母线电容**（吸收换流尖峰）
- [ ] **栅极电阻**（每个管子）
- [ ] **栅源下拉**（每个管子）
- [ ] **过流保护**（采样 + 比较器 + 快速关断）
- [ ] **温度保护**（NTC）

### 7.4 死区时间 ★

**问题**：MOS 关断需要时间（$t_{d(off)}+t_f$）。如果上管还没完全关断就开下管，两个管子会**同时导通**。

**后果**：$V_{CC}$ 直接对地短路。

**短路电流估算：**
$$I_{shoot}=\frac{V_{CC}}{R_{DS(on),上}+R_{DS(on),下}}$$

**例**：24 V 母线，两个 15 mΩ
$$I=\frac{24}{0.03}=800\text{ A}$$

**而瞬时功率** $=24\times800=19.2\text{ kW}$，2 µs 内产生 **38.4 mJ** 的能量。

**对比管子的雪崩能量 $E_{AS}$（通常几十~几百 mJ）** → **几乎必然炸管**。

**死区的权衡：**

| 死区太短 | 死区太长 |
|---|---|
| 有直通风险 → 炸管 | 体二极管导通时间长 → 损耗大、效率低 |

**常用值**：**100 ns ~ 1 µs**（取决于驱动能力和管子速度）。

### 7.5 防反接（P-MOS）☆

串联二极管的方案有 $V_F$ 损耗（1 A 时约 0.5~1 W）。用 P-MOS 可以大幅降低：

```
   输入+ ──── S ┌──────┐ D ──── 输出+
               │ P-MOS│
   输入− ──────┤ G    │
               └──────┘
```

**工作过程**：
1. 正常极性：体二极管先导通（压降 0.7 V）
2. 栅极被拉到低电平 → 沟道导通 → 压降降到 $I\cdot R_{DS(on)}$（如 1 A × 50 mΩ = 0.05 V）
3. 反接：体二极管反向截止，且 $V_{GS}$ 为正 → 不导通 → **保护成功**

### 7.6 PWM 调速（比赛最常用）

**低边 PWM + 续流二极管** 是最简单的直流电机调速方案：

```
        VCC
         │
       [电机]
         │
         ├──────┤◁├──────┐   ← 续流二极管（阴极接 VCC 侧）
         │               │
         D               │
         │               │
   G ────┤ N-MOS         │
         │               │
         S               │
         │               │
        GND ─────────────┘
```

**PWM 参数选择：**

| 参数 | 推荐 | 理由 |
|---|---|---|
| 频率（电机） | **1~20 kHz** | 太低有啸叫、电流脉动大；太高开关损耗大 |
| 频率（LED 调光） | >1 kHz | 避免可见闪烁 |
| 占空比 | 0~100% | 平均电压 $=D\times V_{CC}$，近似线性调速 |

**一个反直觉的现象**：
- 占空比 **100%** 时 MOS **最凉**（一直导通，只有导通损耗）
- 占空比 **50%** 时 MOS **更热**（因为增加了开关损耗，且开关瞬间电压电流同时大）

> **这个现象在实验里非常明显，也是"开关损耗真实存在"的直接证据。**

## 8. 故障模式 ★

### 8.1 九种死法

| # | 死法 | 现象 | 根本原因 | 预防 |
|---|---|---|---|---|
| 1 | **栅极驱动不足** | 管子发烫、带不动负载 | $V_{GS}$ 落在亚阈值区/临界区，$R_{DS(on)}$ 暴增 | 用逻辑电平 MOS 或驱动 IC；核对手册 $V_{GS}$ 条件 |
| 2 | **上下管直通** | 一上电就炸、有爆响 | 死区不足或时序错误 | 加死区；用带死区的驱动 IC |
| 3 | **$V_{DS}$ 尖峰超限** | 随机损坏、无明显规律 | 感性负载换流尖峰 + 走线电感 | 续流二极管、RC 吸收、母线电容、提高耐压裕量 |
| 4 | **散热不足** | 热、逐渐失效、焊点变色 | 热设计没做或做错 | 按五步法验算；铺铜、散热片 |
| 5 | **栅极悬空误导通** | 上电即导通、不受控 | 缺栅源下拉电阻 | **必加 10 kΩ 下拉** |
| 6 | **寄生振荡** | 波形振铃、EMI 超标、随机炸管 | 栅极走线长、功率回路面积大、$R_g$ 太小 | $R_g$、缩短走线、减小回路面积 |
| 7 | **静电击穿栅氧** | 拿起来就是坏的 | 无防静电措施 | 防静电台垫、先放电、防静电袋 |
| 8 | **体二极管反向恢复** | 半桥效率低、尖峰大 | 高频换流时体二极管恢复慢 | 外并肖特基、优化死区、用带快速体二极管的型号 |
| 9 | **$V_{GS}$ 过压** | 栅氧击穿 | 驱动电压超 ±20 V、或 $V_{CC}$ 高时没钳位 | 加齐纳钳位、分压 |

### 8.2 排查逻辑（不需要仪器也能推理）

**有仪器时的顺序（记住这个逻辑）：**

| 步骤 | 量什么 | 正常应该是什么 | 异常说明什么 |
|---|---|---|---|
| 1 | **$V_{GS}$** | 等于驱动电压 | 不对 → 驱动电路问题 |
| 2 | **$V_{DS}$** | 导通时几十~几百 mV | 几伏 → 驱动不足；≈$V_{CC}$ → 没导通 |
| 3 | **栅极波形** | 有平台、无振铃 | 振铃 → 寄生参数问题 |
| 4 | **断电测体二极管** | 单向导通 | 双向通/不通 → 管子坏了 |
| 5 | **负载与续流路径** | 感性负载有续流 | 没有 → 尖峰问题 |

**没有仪器时的推理方法：**

1. **先问"它本该怎样"**：画出理想波形，和现象对比
2. **从现象倒推**：管子烫 → 只有三种可能（驱动不足 / 散热不够 / 开关损耗大）
3. **用排除法**：能算的都算一遍（功耗、结温），算不过关的就是原因
4. **查手册核对**：$V_{GS}$ 够不够？$V_{DS}$ 够不够？

> **这套推理方法在实验室里也一样用**：先分析，再拿仪器验证。**不要一上来就拿探头到处戳。**

## 9. 选型方法 ★★

### 9.1 从需求倒推（四步）

**步骤 1：明确需求**

| 需求项 | 例子 |
|---|---|
| 母线电压 | 12 V |
| 最大电流 | 2 A |
| 驱动电压（由控制器决定） | **3.3 V** |
| 开关频率 | 20 kHz |
| 负载类型 | 感性（电机） |
| 环境温度 | 40 °C |

**步骤 2：定耐压**
$$V_{DSS}\ge 12\times3=36\text{ V}\quad\Rightarrow\quad\text{选 40 V 或 55 V}$$

（**感性负载取 3 倍**，因为换流尖峰会超过母线电压）

**步骤 3：定 $R_{DS(on)}$ 上限（用热反推）**

假设 $R_{th(j-a)}=62\ °C/W$，$T_{j,max}=150\ °C$，$T_a=40\ °C$：

$$P_{允许}=\frac{150-40}{62}=1.77\text{ W}$$

$$R_{DS(on),hot}\le\frac{P}{I^2}=\frac{1.77}{4}=0.44\ \Omega$$

$$R_{DS(on),25°C}\le\frac{0.44}{1.7}\approx0.26\ \Omega=260\text{ m}\Omega$$

→ **只要 $R_{DS(on)}$ 在 3.3 V 下小于 260 mΩ 就安全**（很宽松）

**步骤 4：核对驱动条件（最关键）**

**必须在手册里找到 $V_{GS}=3.3\text{ V}$（或 2.5 V）条件下的 $R_{DS(on)}$ 数据。**

- 有 → ✅ 可以
- 只有 4.5 V 和 10 V → ⚠️ 4.5 V 的数据可以参考（3.3 V 会比它更大），但**余量要留足**
- 只有 10 V → ❌ **换型号或加驱动 IC**

### 9.2 选型速查表（按应用场景）

> **以下是"参数组合"的典型范围，不是具体型号推荐。实际选型请查手册。**

| 应用场景 | $V_{DSS}$ | $R_{DS(on)}$ 目标 | $V_{GS}$ 驱动 | 封装 | 备注 |
|---|---|---|---|---|---|
| **3.3 V 逻辑直驱，小电流** | 20~30 V | 20~50 mΩ @4.5V | 2.5~4.5 V | SOT-23 | **必须逻辑电平** |
| **5 V 驱动，中等电流** | 30~60 V | 10~30 mΩ @4.5V | 4.5 V | SOT-23 / DPAK | 逻辑电平 |
| **12 V 电机驱动（低边）** | 30~60 V | 10~30 mΩ @10V | 10~12 V | DPAK / TO-220 | 需驱动 IC 或推挽 |
| **24 V 电机驱动** | 60~100 V | 20~50 mΩ @10V | 10~12 V | TO-220 / D2PAK | 注意尖峰 |
| **半桥/H 桥上下管** | 40~100 V | 10~50 mΩ @10V | 10~12 V（自举） | DPAK / TO-220 | **要 $Q_g$ 小** |
| **同步整流（BUCK 下管）** | 30~60 V | **尽量低**（<10 mΩ） | 10 V | DPAK / 大封装 | 体二极管 $t_{rr}$ 要短 |
| **高边开关** | — | P 沟道：50~200 mΩ | 需拉低 | SOT-23 / SO-8 | P 沟道电阻大 |
| **防反接** | ≥ 母线 ×1.5 | P 沟道，几十 mΩ | — | SO-8 / DPAK | 压降比二极管小 |

> **下面是常见型号的参数量级，用来建立直觉。具体数值以各厂家手册为准。**

| 型号 | 类型 | $V_{DSS}$ | $R_{DS(on)}$（典型条件） | $Q_g$ | 性格 |
|---|---|---|---|---|---|
| AO3400 类 | N，逻辑电平 | 30 V | ~30 mΩ @4.5V | ~5 nC | **小信号首选，3.3 V 可驱** |
| SI2302 类 | N，逻辑电平 | 20 V | ~50 mΩ @4.5V | ~3 nC | 更低电压，可直驱 |
| IRLZ44N 类 | N，逻辑电平 | 55 V | ~25 mΩ @5V | ~48 nC | 5 V 逻辑驱动，中大功率 |
| FQP30N06L 类 | N，逻辑电平 | 60 V | ~40 mΩ @10V | ~20 nC | 5 V 可驱，TO-220 |
| IRF540N 类 | N，**标准** | 100 V | ~44 mΩ **@10V** | ~71 nC | ⚠️ **需 10 V 驱动** |

**从表里能看出两条规律：**

> ▲ **IRF540N 是最著名的"新手杀手"**：便宜、好买、参数看起来很强（100 V、33 A），但很多人不知道它**需要 10 V 驱动**，用 5 V 单片机直驱必然发热。

### 9.4 选型检查清单

拿到一个候选型号，逐条打勾：

- [ ] $V_{DSS}$ ≥ 工作电压 × 2~3（感性负载 ×3）
- [ ] 手册里**有我需要的 $V_{GS}$ 下的 $R_{DS(on)}$ 数据**
- [ ] 用该 $R_{DS(on)}$ 的 **Max** 值 + 热态倍率，算出 $T_j$ < $T_{j,max}$ - 20°C（留余量）
- [ ] $V_{GS(th)}$ 范围保证：能可靠开通（$V_{GS,drive}\gg V_{GS(th),max}$），也能可靠关断（$V_{GS,off}<V_{GS(th),min}$）
- [ ] $Q_g$ 匹配我的驱动能力：$I_{drive}=Q_g/t_{switch}$ 可实现
- [ ] $V_{GS(max)}$ 不会被我的驱动电路超过
- [ ] $R_{th}$ 和封装适合我的散热方式

## 附录 A：公式速查

| 公式 | 用途 |
|---|---|
| $Q_g=C_{iss}\cdot V_{drive}$ | 栅极电荷 |
| $I_{drive}=\dfrac{Q_g}{t_{switch}}$ | 驱动电流需求 |
| $I_{peak}\approx\dfrac{V_{drive}}{R_g}$ | 栅极峰值电流 |
| $P_{cond}=I_D^2\cdot R_{DS(on),hot}$ | 导通损耗 |
| $P_{sw}\approx\dfrac{1}{2}V_{DS}I_D(t_r+t_f)f_{sw}$ | 开关损耗 |
| $P_{gate}=Q_g V_{GS}f_{sw}$ | 栅极驱动损耗 |
| $R_{DS(on)}(T_j)=R_{25}[1+k(T_j-25)]$ | 热态电阻 |
| $T_j=T_a+P\cdot R_{th(j-a)}$ | 结温 |
| $R_{th(允许)}=\dfrac{T_{j,max}-T_a}{P}$ | 允许热阻 |
| $I_{max}\approx\sqrt{\dfrac{T_{j,max}-T_a}{R_{DS(on),hot}R_{th(j-a)}}}$ | 实际可承受电流 |
| $I_{shoot}=\dfrac{V_{CC}}{R_{上}+R_{下}}$ | 直通电流 |
| $V_{ov}=V_{GS}-V_{GS(th)}$ | 过驱动电压 |

**临界条件**（判断工作区）：

| 条件 | 工作区 |
|---|---|
| $V_{GS}<V_{GS(th)}$ | 截止 |
| $V_{GS}>V_{GS(th)}$ 且 $V_{DS}<V_{ov}$ | **可变电阻区（开关用这个）** |
| $V_{GS}>V_{GS(th)}$ 且 $V_{DS}>V_{ov}$ | 饱和区（恒流区） |

## 附录 B 答案

**1.** 栅极与沟道之间是 SiO₂ 绝缘层，稳态无电流通路，故静态不耗电。但栅极本质是电容 $C_{iss}$，每次开关要搬运电荷 $Q_g$，所需电流 $I=Q_g/t_{switch}$。若 $t_{switch}$ 要求 100 ns 而 $Q_g=30\text{ nC}$，就需 300 mA 脉冲电流。

**2.** N 沟道体二极管 **S→D**（阳极在 S）。因为衬底是 P 型并与源极 S 短接，漏区是 N+，二者构成 PN 结，阳极在 P 侧即 S 侧。

**3.** BJT 的饱和区：$V_{CE}$ 很小，像**闭合的开关**，导通最好，**做开关要用这个区**。MOS 的饱和区：$V_{DS}$ 较大、沟道夹断，像**恒流源**，导通很差，**做开关绝不能用**。MOS 做开关要用**可变电阻区（线性区）**。

**4.** 亚阈值区是 $V_{GS}$ 略低于 $V_{GS(th)}$ 的区域，此时沟道未完全形成但已有微小电流，且随 $V_{GS}$ **指数增长**。危险原因：若驱动电压落在这一区域边缘，$R_{DS(on)}$ 会比标称值大几十倍 → 功耗爆炸 → 烧管。

**5.** 测 $V_{DS}$。充分导通时 $V_{DS}=I_D\cdot R_{DS(on)}$，只有**几十~几百 mV**。若 $V_{DS}$ 有几伏 → 驱动不足；若 $V_{DS}\approx V_{CC}$ → 根本没导通。

**6.** 栅氧层只有几十纳米厚，耐压仅约 **±20 V**，而人体静电可达几千伏以上。静电击穿氧化层会导致栅极与沟道短路，**永久报废**。

**7.** **增强型**：默认关断，需要加电压"增强"出沟道（适合做开关）。**耗尽型**：默认导通（本身就有沟道），需要加电压才能关断。

**8.** 通常 **2~3 行**（如 $V_{GS}=10\text{ V}$ 一行、$4.5\text{ V}$ 一行）。因为 $R_{DS(on)}$ 强烈依赖 $V_{GS}$，**每一行都有自己的 Test Conditions**。必须找到你实际驱动电压对应的那一行，否则数据无意义。

**9.** 因为 $I_D$ 通常标的是 $T_c=25°C$ 的理想值。实际可承受电流由热决定：$I_{max}\approx\sqrt{(T_{j,max}-T_a)/(R_{DS(on),hot}\cdot R_{th(j-a)})}$。举例：手册标 30 A 的管子，实际可能只能过 4~5 A。

**10.** 随温度**上升**（正温度系数），约 **0.4%~0.8%/°C**。热设计时必须用"热态电阻"，一般取 25°C 值的 **1.5~1.7 倍**（目标 $T_j\approx100°C$）。用 25°C 的值会严重低估发热。

**11.** 逻辑电平 MOS 的低压驱动性能好。**识别方法**：手册的 $R_{DS(on)}$ 有 $V_{GS}=4.5\text{ V}$（甚至 2.5 V）条件下的数据行。只标 $V_{GS}=10\text{ V}$ 的是标准 MOS。

**12.** 因为 MOS 的 $R_{DS(on)}$ 是**正**温度系数：温度高的管子电阻大、分到的电流小 → **自动均流**。而 BJT 的 $V_{BE}$ 是**负**温度系数：温度高的管子导通更强、抢更多电流、更热 → **热失控**。

**13.** 米勒平台是栅极充电过程中 $V_{GS}$ **停滞不变**的一段。发生在 $V_{DS}$ 快速下降的阶段：此时 $V_{DS}$ 变化通过 $C_{gd}$ 耦合到栅极，把驱动电流"吸走"，$V_{GS}$ 停住。**为什么损耗最大**：这一阶段**电流已建立（$I_D$ 大）、电压还很高（$V_{DS}$ 大）**，$P=V\cdot I$ 同时很大。

**14.** $I_{drive}=Q_g/t=40\text{ nC}/200\text{ ns}=0.2\text{ A}=200\text{ mA}$。**20 mA 不行**（差 10 倍），会导致开关时间长达 2 µs，开关损耗大、管子发热。需要驱动 IC 或推挽电路。

**15.** **太小**：开关快、损耗小，但 dV/dt 大 → 振铃、EMI、可能被干扰误开通，栅极峰值电流可能超过驱动能力。**太大**：开关慢 → 米勒平台变长 → 开关损耗大 → 发热。

**16.** 作用：给栅极确定电位（默认关断）+ 泄放 $C_{iss}$ 上的电荷。**不装**：单片机复位期间 IO 是高阻态，栅极悬空，电荷无处泄放 → MOS 误导通 → **上电瞬间电机就全速转**（程序还没跑）。

**17.** 解决**高边 N 沟道驱动**问题：高边源极电位接近 $V_{CC}$，要让 $V_{GS}>10\text{ V}$ 就需要栅极高于 $V_{CC}$，而系统只有 $V_{CC}$。自举电容在低边导通时充电，切换后"浮"在源极上，把栅极抬到约 $2V_{CC}$。**限制**：① 占空比不能 100%（否则电容无法充电）；② 上电需要预充电。

**18.** 因为**栅极电压必须相对源极测量**。低边开关的源极接 GND，栅极只要给正的驱动电压即可。高边 N 沟道的源极电位接近 $V_{CC}$，栅极必须**高于 $V_{CC}$**，所以需要自举或电荷泵产生"浮动电源"。

**19.** 死区时间是上下管切换之间故意插入的"两个管子都不导通"的时间。**不加**：MOS 关断需要时间，一个还没关断另一个就开了 → 上下管同时导通 → $V_{CC}$ 直接对地短路 → 电流可达数百安培 → **瞬间炸管**。

**20.** 占空比 100% 时 MOS 一直导通，**只有导通损耗** $I^2R_{DS(on)}$。占空比 50% 时增加了**开关损耗**：每次开关的过渡期间 $V_{DS}$ 和 $I_D$ 同时很大，$P_{sw}\approx\frac{1}{2}V_{DS}I_D(t_r+t_f)f_{sw}$。而且 50% 时开关动作最频繁，所以总损耗更大。
